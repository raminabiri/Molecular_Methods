# ۰۱ — جداول مرجع و برگه‌ی فرمول‌های مرکزی

> **این فایل مرجع مشترک کل مخزن است.** فصل‌های دیگر به‌جای تکرار فرمول‌ها به این‌جا ارجاع می‌دهند تا هیچ تناقضی بین فصل‌ها ایجاد نشود.

---

## جدول ۱ — برگه‌ی فرمول‌های مرکزی

### ۱.۱. محلول‌سازی
| کمیت | فرمول | یادداشت |
| :--- | :--- | :--- |
| جرم برای مولاریته‌ی مشخص | $m\ (\text{g}) = M\ (\text{mol/L}) \times V\ (\text{L}) \times MW\ (\text{g/mol})$ | MW را از برچسب همان بطری بخوانید (فرم آبدار) |
| رقیق‌سازی | $C_1V_1 = C_2V_2$ | واحدهای دو طرف یکسان |
| رقت کل در رقت سریالی | $D_{\text{total}} = D_1 \times D_2 \times \dots$ | |
| مولاریته‌ی معرف غلیظ | $M = \dfrac{1000 \times \rho \times w}{MW}$ | $\rho$ = چگالی (g/mL)، $w$ = کسر وزنی |
| حجم حلال برای پرایمر ۱۰۰ میکرومولار | $V\ (\mu\text{L}) = \text{nmol} \times 10$ | |
| نیروی سانتریفیوژ | $\text{RCF} = 1.118\times10^{-5} \times r_{(\text{cm})} \times \text{rpm}^2$ | |
| | $\text{rpm} = \sqrt{\text{RCF} / (1.118\times10^{-5}\times r)}$ | |
| هندرسون-هاسلباخ | $\text{pH} = \text{p}K_a + \log([\text{A}^-]/[\text{HA}])$ | محدوده‌ی کاری $\text{p}K_a \pm 1$ |
| بیر-لامبرت | $A = \varepsilon \cdot c \cdot l$ | $l$ معمولاً ۱ سانتی‌متر |

### ۱.۲. اسیدهای نوکلئیک
| کمیت | فرمول یا مقدار | یادداشت |
| :--- | :--- | :--- |
| غلظت از $A_{260}$ | dsDNA: $A_{260}\times50$؛ ssDNA: $\times33$؛ RNA: $\times40$ (µg/mL، مسیر ۱ سانتی‌متر) | × فاکتور رقت |
| خلوص | $A_{260}/A_{280}$: DNA حدود ۱.۸، RNA حدود ۲.۰؛ $A_{260}/A_{230}$: حدود ۲.۰ تا ۲.۲ | جزئیات در فصل ۰۲ |
| جرم مولی متوسط | dsDNA ≈ **650 g/mol به ازای هر bp** (نمک سدیم)؛ ssDNA ≈ 330 g/mol/nt؛ ssRNA ≈ 340 g/mol/nt | برخی کیت‌های NGS عدد **660** را برای dsDNA به کار می‌برند (اختلاف حدود ۱.۵٪) |
| جرم یک نسخه‌ی ژنوم یا مولکول | $m\ (\text{g}) = \dfrac{L_{\text{bp}} \times 650}{6.022\times10^{23}}$ | |
| تعداد نسخه (Copy number) | $\text{copies} = \dfrac{m_{(\text{ng})} \times 6.022\times10^{23}}{L_{\text{bp}} \times 650 \times 10^{9}}$ | |
| ng ↔ pmol (dsDNA) | $\text{pmol} = \dfrac{\text{ng}\times1000}{L_{\text{bp}}\times650}$ | |
| مولاریته‌ی کتابخانه‌ی NGS | $\text{nM} = \dfrac{C_{(\text{ng}/\mu\text{L})}\times10^6}{660 \times L_{\text{avg bp}}}$ | فصل ۱۳ |
| نسبت مولی لیگاسیون | $\text{ng}_{\text{insert}} = \text{ng}_{\text{vector}} \times \dfrac{L_{\text{insert}}}{L_{\text{vector}}} \times \text{ratio}$ | فصل ۱۴ |
| کارایی ترانسفورماسیون | $\text{cfu}/\mu\text{g} = \dfrac{\text{colonies}}{\mu\text{g DNA}_{\text{plated}}}$ | µg واقعاً پلیت‌شده |

### ۱.۳. PCR و qPCR
| کمیت | فرمول | یادداشت |
| :--- | :--- | :--- |
| $T_m$ والاس (پرایمرهای کوتاه، تقریبی) | $T_m = 2(A+T) + 4(G+C)$ | فقط برای حدود ۱۴ تا ۲۰ نوکلئوتید؛ برای طراحی واقعی از روش **Nearest-neighbor** استفاده کنید |
| $T_m$ پایه برای پرایمرهای بلندتر | $T_m = 64.9 + 41\times\dfrac{(G+C) - 16.4}{N}$ | بدون اصلاح نمک؛ تقریبی |
| کارایی qPCR از منحنی استاندارد | $E = 10^{-1/\text{slope}} - 1$ | slope = −3.32 → ۱۰۰٪؛ قابل‌قبول: slope بین −3.6 و −3.1 (حدود ۹۰ تا ۱۱۰٪) |
| فاکتور تکثیر در هر سیکل | $1 + E$ (بین ۱ و ۲) | در LinRegPCR: $10^{\text{slope}}$ رگرسیون $\log_{10}F$ در برابر سیکل |
| روش لیواک (ΔΔCt) | $\text{FC} = 2^{-\Delta\Delta C_t}$؛ $\Delta C_t = C_{t,\text{target}} - C_{t,\text{ref}}$؛ $\Delta\Delta C_t = \Delta C_{t,\text{sample}} - \Delta C_{t,\text{control}}$ | فقط اگر کارایی هدف و مرجع حدود ۱۰۰٪ و نزدیک به هم باشد |
| روش فافل (Pfaffl) | $\text{ratio} = \dfrac{(1+E_{\text{target}})^{\Delta C_{t,\text{target}}(\text{control}-\text{sample})}}{(1+E_{\text{ref}})^{\Delta C_{t,\text{ref}}(\text{control}-\text{sample})}}$ | با کارایی‌های متفاوت |

### ۱.۴. میکروب‌شناسی
| کمیت | فرمول یا مقدار |
| :--- | :--- |
| شمارش زنده | $\text{cfu/mL} = \dfrac{\text{colonies}}{\text{volume plated (mL)} \times \text{dilution}}$ |
| OD600 و تعداد سلول *E. coli* | $\text{OD}_{600} = 1 \approx 8\times10^8$ سلول در میلی‌لیتر (**تقریبی و وابسته به دستگاه و سویه**؛ برای کار دقیق منحنی کالیبراسیون خودتان را بسازید) |
| استاندارد مک‌فارلند ۰.۵ | حدود $1.5\times10^8$ cfu/mL |
