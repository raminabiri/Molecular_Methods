# ۱۶ — جداول مرجع: MALDI-TOF و شناسایی مولکولی

> ⚠️ عددهای نشان‌دار با **🔎** را پیش از استفاده با **دفترچه‌ی همان دستگاه، همان نسخه‌ی نرم‌افزار و همان Lot معرف** تأیید کنید. آستانه‌های تفسیر باید **در آزمایشگاه خودتان اعتبارسنجی** شده باشند.

---

## جدول ۱ — فرمول‌ها
| کمیت | فرمول |
| :--- | :--- |
| سرعت یون پس از شتاب | $v = \sqrt{2zeV/m}$ |
| **زمان پرواز** | $t = L\sqrt{m/2zeV}$ |
| تناسب عملی | $t \propto \sqrt{m/z}$ ← جرم **۴ برابر** = زمان **۲ برابر** |
| نسبت دو زمان پرواز | $t_2/t_1 = \sqrt{m_2/m_1}$ |
| اختلاف زمانی برای تغییر کوچک جرم | $\Delta t/t \approx \tfrac{1}{2}\,\Delta m/m$ |
| **قدرت تفکیک** | $R = m/\Delta m$ (معمولاً $\Delta m$ = عرض در نیمه‌ی ارتفاع) |
| خطای جرمی | $\text{خطا (Da)} = m \times \text{ppm} \times 10^{-6}$ |
| رقت از استوک | $V_{\text{استوک}} = C_{\text{نهایی}}V_{\text{نهایی}}/C_{\text{استوک}}$ |
| ناهمسانی توالی | $\text{تعداد باز ناهمسان} = L_{\text{هم‌ترازی}} \times (1 - \text{شباهت})$ |
| پوشش هم‌ترازی | $\text{پوشش} = L_{\text{هم‌ترازی}} / L_{\text{محصول}} \times 100$ |
| ظرفیت یک ران | $(N_{\text{اسپات}} - N_{\text{کنترل}}) / N_{\text{تکرار هر نمونه}}$ |
> **ثابت‌ها:** $1\ \text{Da} = 1{,}6605\times10^{-27}\ \text{kg}$ · $e = 1{,}602\times10^{-19}\ \text{C}$

## جدول ۲ — 🔎 پارامترهای دستگاه (شناسایی میکروبی)
| پارامتر | مقدار معمول | توضیح |
| :--- | :--- | :--- |
| **لیزر** | نیتروژن **۳۳۷ nm** یا Nd:YAG **۳۵۵ nm** | پالس نانوثانیه‌ای؛ ماتریکس در UV جذب می‌کند |
| **ولتاژ شتاب‌دهنده** | حدود **۲۰ kV** | به همه‌ی یون‌ها انرژی جنبشی یکسان می‌دهد |
| **حالت** | **خطی مثبت (Linear positive)** | حساسیت بیشتر در جرم بالا؛ تفکیک کمتر از رفلکترون |
| **پنجره‌ی جرمی** | **۲٫۰۰۰ تا ۲۰٫۰۰۰ Da** | ناحیه‌ی پروتئین‌های ریبوزومی |
| طول لوله‌ی پرواز | حدود ۱ متر (مستقیم) | رفلکترون مسیر مؤثر را دو برابر می‌کند |
| **خلأ لوله** | $10^{-6}$ تا $10^{-7}$ mbar | مسیر آزاد میانگین > طول لوله |
| پمپ‌ها | روتاری (پیش‌خلأ) + **توربومولکولار** | با **قفل خلأ** برای ورود تارگت |
| آشکارساز | **صفحه‌ی میکروکانال (MCP)** یا SEM | تقویت برخورد یون |
| تصحیح تفکیک | **استخراج تأخیری** (± رفلکترون) | جبران پراکندگی سرعت/انرژی اولیه |
| زمان پرواز نمونه‌وار | ۲ kDa ≈ ۲۳ µs · ۱۰ kDa ≈ ۵۱ µs · ۲۰ kDa ≈ ۷۲ µs | (با L=۱ m و V=۲۰ kV) |

## جدول ۳ — معرف‌ها: ساخت و نگهداری
| معرف | ساخت | 🔎 نگهداری | هشدار |
| :--- | :--- | :--- | :--- |
| **حلال آلی** (۵۰٪ ACN + ۲٫۵٪ TFA) | برای ۱ mL: **۴۷۵ µL آب HPLC + ۵۰۰ µL ACN + ۲۵ µL TFA** (به همین ترتیب) | دمای اتاق، لوله‌ی بسته، تا ~۱ ماه | ⚠️ زیر هود؛ TFA سوزاننده |
| **ماتریکس HCCA اشباع** | ~۲٫۵ mg HCCA در ۲۵۰ µL حلال آلی؛ ۱ دقیقه ورتکس؛ ۵ دقیقه ته‌نشینی | دمای اتاق، دور از نور، **هفتگی تازه** | ❗ **فقط محلول رویی**؛ در یخچال نگه ندارید |
| **اسید فرمیک ۷۰٪** | برای ۱ mL: **۳۰۰ µL آب + ۷۰۰ µL اسید ۱۰۰٪** | لوله‌ی بسته، زیر هود | ⚠️ **اسید را به آب** اضافه کنید |
| **اتانول مطلق** | آماده | دمای اتاق | آتش‌گیر |
| **BTS (کالیبراتور)** | بازسازی طبق دفترچه؛ **الیکوت تک‌مصرف** | **−۲۰°C** | ❗ ذوب-انجماد مکرر = کالیبراسیون ناموفق |
| **آب** | درجه‌ی **HPLC/فوق‌خالص** | — | آب مقطر معمولی کافی نیست |
> نسبت نهایی عصاره در استخراج کامل (۱:۱): **۳۵٪ اسید فرمیک + ۵۰٪ استونیتریل**.

## جدول ۴ — انتخاب روش آماده‌سازی نمونه
| ارگانیسم / وضعیت | روش اول | اگر امتیاز کافی نبود |
| :--- | :--- | :--- |
| گرم-منفی‌های روتین (انتروباکترال‌ها، سودوموناس) | **اسمیر مستقیم** | استخراج روی تارگت ← استخراج کامل |
| گرم-مثبت‌ها (استافیلوکوک، انتروکوک، استرپتوکوک) | **استخراج روی تارگت** | **استخراج کامل** |
| **مخمر و قارچ** | **استخراج کامل** | تکرار با زیست‌توده‌ی بیشتر؛ کشت استانداردشده |
| کلنی **موکوئید/کپسول‌دار** | **استخراج کامل** | شست‌وشوی اولیه با آب، سپس استخراج کامل |
| بی‌هوازی‌ها | اسمیر مستقیم یا روی تارگت | استخراج کامل |
| کلنی **بسیار ریز/کم‌رشد** | انکوباسیون بیشتر؛ **استخراج کامل** | ۱۶S rRNA |
| ⚠️ **مایکوباکتریوم** | **پروتکل و کتابخانه‌ی مخصوص** پس از غیرفعال‌سازی تأییدشده | *hsp65*/*rpoB* |
| هر نمونه‌ی **شکست‌خورده‌ی تکراری** | استخراج کامل از **کلنی تازه** | **۱۶S rRNA** |

## جدول ۵ — تفسیر امتیاز (🔎 دو پلتفرم)
| | **Bruker MALDI Biotyper** | **bioMérieux VITEK MS** |
| :--- | :--- | :--- |
| سنجه | **log(score)**، بازه‌ی ۰ تا ۳ | **درصد اطمینان** تا ۹۹٫۹٪ |
| سطح گونه | **۲٫۰۰۰ – ۳٫۰۰۰** (۲٫۳۰۰+ = اطمینان بالا) | طبق آستانه‌ی نرم‌افزار و اعتبارسنجی |
| سطح جنس | **۱٫۷۰۰ – ۱٫۹۹۹** | پیام «کم‌تفکیک/چند گزینه» |
| غیرقابل اعتماد | **< ۱٫۷۰۰** | زیر آستانه یا بدون تطبیق |
| مرجع مقایسه | **MSP** (طیف مرجع گونه) | **بین‌های جرمی وزن‌دار** |
| کالیبراتور | **BTS** در هر ران | کشت استاندارد *E. coli* در هر **گروه اکتساب** |
| تارگت | فولادی **قابل استفاده‌ی مجدد** (تمیزکاری اجباری) | **اسلاید یک‌بار‌مصرف** |
| کتابخانه‌ی محلی | **ساخت MSP ممکن است** | محدودتر |
> ⚠️ **این دو عدد قابل تبدیل یا مقایسه نیستند.** هر گزارش باید **پلتفرم، نسخه‌ی کتابخانه، امتیاز و روش آماده‌سازی** را ذکر کند.

## جدول ۶ — 🔎 گروه‌هایی که MALDI-TOF تفکیک نمی‌کند

| :--- | :--- | :--- |
| ***E. coli*** / ***Shigella*** | ⚠️ شیگلا را رد نکنید | تحرک، لیزین، لاکتوز، **سرولوژی**، PCR (*ipaH*) |
| ***S. pneumoniae*** / گروه ***S. mitis-oralis*** | «*Streptococcus* گروه میتیس» تا تأیید | **اپتوخین**، **حل‌پذیری در صفرا**، Quellung، *lytA* |
| کمپلکس ***Enterobacter cloacae*** | «کمپلکس *E. cloacae*» | *hsp60*، MLSA، WGS |
| کمپلکس ***Burkholderia cepacia*** | «کمپلکس *B. cepacia*» | *recA* |
| کمپلکس ***A. baumannii-calcoaceticus*** | نام **کمپلکس** | *rpoB*، WGS |
| **کورینه‌باکتریوم/اکتینومیست** | جنس | **۱۶S**، *rpoB* |
| **مایکوباکتریوم‌ها** | کمپلکس/گروه | *hsp65*، *rpoB* · ⚠️ BSL-3 |

| **سروتیپ‌ها** (مثلاً سالمونلا) | ❌ MALDI سروتیپ نمی‌دهد | سرولوژی، WGS |

## جدول ۷ — ۱۶S rRNA: پرایمرها و تفسیر
### ۷.۱. 🔎 پرایمرها
| پرایمر | توالی (۵'→۳') | کاربرد |
| :--- | :--- | :--- |
| **27F** | `AGAGTTTGATCMTGGCTCAG` | رفت، ابتدای ژن |
| **1492R** | `TACGGYTACCTTGTTACGACTT` | برگشت، انتهای ژن |
| 785F / 907R | (پرایمرهای داخلی؛ طبق مرجع آزمایشگاه) | پوشش کامل در توالی‌یابی |
> M = A/C · Y = C/T · محصول **~۱٫۴ تا ۱٫۵ kb** · 🔎 دمای اتصال ~۵۵°C، بسط ۹۰ ثانیه، ۳۰ تا ۳۵ چرخه.

### ۷.۲. 🔎 آستانه‌های شباهت
| شباهت | تفسیر | معادل ناهمسانی در ۱٫۴۵۰ bp |
| :--- | :--- | :--- |
| **≥ ۹۹٪** (برخی مراجع ۹۸٫۷٪) | احتمالاً **همان گونه** | ≤ ~۱۵ باز |
| **۹۷ – ۹۹٪** | **جنس** مشخص، گونه نامطمئن | ~۱۵ تا ۴۴ باز |
| **< ۹۷٪** | گونه/جنس نامشخص یا جدید | > ~۴۴ باز |
> ❗ سه شرط اعتبار: **پوشش بالا و هم‌ترازی تمام‌طول**، **بررسی چند تطبیق برتر** (نه فقط اولی)، و پایگاه داده‌ی **کیوریت‌شده با سویه‌ی تیپ**.

### ۷.۳. اهداف جایگزین وقتی ۱۶S کافی نیست
| گروه | هدف |
| :--- | :--- |
| کمپلکس *Enterobacter*، *Acinetobacter* | ***rpoB***، MLSA، WGS |
| گروه میتیس/پنوموکوک | *sodA*، *rpoB*، *gyrB* |
| مایکوباکتریوم | ***hsp65***، *rpoB*، ITS |
| **قارچ‌ها** (۱۶S وجود ندارد) | **ITS**، ۲۸S/D1-D2، *TEF1α* |
| تفکیک سویه | **فصل ۱۷** (MLST، PFGE، cgMLST) |

## جدول ۸ — کنترل‌های لازم
| کنترل | در کدام روش | هدف | اگر خراب بود |
| :--- | :--- | :--- | :--- |

| **سویه‌ی کنترل شناخته** | MALDI، روزانه (QC) | صحت کل گردش‌کار + **پایش روند** | بازبینی معرف، تکنیک، دستگاه |

## جدول ۹ — MALDI-TOF در برابر ۱۶S: انتخاب روش
| معیار | MALDI-TOF | ۱۶S rRNA |
| :--- | :--- | :--- |
| 🔎 زمان | **۵ تا ۳۰ دقیقه** | ۱ تا ۲ روز |
| 🔎 هزینه‌ی هر نمونه | **بسیار کم** | چند برابر |
| هدف اندازه‌گیری | **پروتئین** (الگوی جرمی) | **DNA** (توالی) |
| مبنا | تطبیق الگو با کتابخانه | مقایسه‌ی توالی با پایگاه داده |
| نیاز به کشت خالص | **اجباری** | بله (یا DNA مستقیم) |
| گونه‌ی غایب از مرجع | **شناسایی نمی‌شود** | توالی همیشه به‌دست می‌آید (تفسیر ممکن است باز بماند) |
| جدایه‌ی نادر/کم‌رشد | ضعیف | **قوی** |
| حجم بالا و روتین | **قوی** | ناکارآمد |
| قارچ رشته‌ای | محدود | **ITS** (نه ۱۶S) |
| تفکیک سویه | ❌ | ❌ (فصل ۱۷) |
| مقاومت دارویی | ❌ (مگر سنجش هیدرولیز) | ❌ (مگر هدف‌گیری ژن مقاومت) |
> **رویه‌ی استاندارد:** MALDI خط اول ← در صورت امتیاز پایین، تناقض با فنوتیپ، یا جدایه‌ی نادر ← **۱۶S** ← در صورت نیاز **ژن دوم/WGS**.

## جدول ۱۰ — عیب‌یابی سریع
| مشاهده | علت اول |
| :--- | :--- |
| همه‌ی اسپات‌ها (با BTS) ضعیف | ماتریکس کهنه یا مشکل دستگاهی |
| فقط نمونه ضعیف، کنترل خوب | زیست‌توده/لیز ناکافی ← استخراج قوی‌تر |
| اسپات سفید و مات، پیک پهن | **لایه‌ی اسمیر ضخیم** |
| کالیبراسیون قبول نمی‌شود | **BTS ذوب-انجماد شده** |
| پیک فراوان ولی بدون تطبیق | **کشت مخلوط** یا گونه‌ی غایب از کتابخانه |
| امتیاز ۱٫۷ تا ۱٫۹۹ | لیز ناکافی ← استخراج کامل |
| امتیاز بالا، تناقض با فنوتیپ | جابه‌جایی نمونه یا **گروه تفکیک‌ناپذیر** |
| نوسان بین اسپات‌ها | کریستال ناهمگن / تکنیک |
| افت تدریجی هفتگی | رانش دستگاه یا Lot جدید معرف |
| پیک غریبه در همه‌ی اسپات‌ها | آلودگی تارگت/ماتریکس (اثر باقی‌مانده) |
| خلأ دیر برقرار می‌شود | **اسپات مرطوب** |
| (۱۶S) NTC باند دارد | آلودگی DNA معرف‌ها |
| (۱۶S) پیک دوگانه‌ی سراسری | **الگوی مخلوط / کشت ناخالص** |
| (۱۶S) شباهت بالا با پوشش کم | هم‌ترازی کوتاه در ناحیه‌ی حفظ‌شده |

## جدول ۱۱ — ایمنی
| مورد | الزام |
| :--- | :--- |
| کشت زنده | **BSL-2**، **کابینت کلاس II**، روپوش و دستکش |
| **استونیتریل** | سمی و فرار ← **هود شیمیایی**، دفع طبق مقررات |
| **TFA / اسید فرمیک** | سوزاننده‌ی شدید، بخار آسیب‌رسان ← هود، دستکش مقاوم، **محافظ چشم**؛ همیشه **اسید به آب** |
| اتانول | آتش‌گیر ← دور از شعله و جرقه |
| ⚠️ ***M. tuberculosis*** | **BSL-3**؛ ورود به مسیر MALDI فقط پس از **غیرفعال‌سازی تأییدشده** و با مجوز کمیته‌ی ایمنی زیستی |
| ⚠️ قارچ رشته‌ای | خطر **اسپور** ← همه‌ی دست‌کاری‌ها در کابینت |
| لیزر دستگاه | هرگز حفاظ یا **اینترلاک** را باز/غیرفعال نکنید |
| سانتریفیوژ کشت | درپوش محکم؛ رویه‌ی ریخت‌پاش BSL-2 |
| ریخت‌پاش شیمیایی | طبق **SDS** و رویه‌ی مؤسسه |
> ⚠️ **دستورالعمل ایمنی زیستی مؤسسه‌ی شما بر این جدول مقدم است.**
