# ۱۸ — عیب‌یابی تخصصی CRISPR-Cas

---

## ۱. هیچ ویرایشی رخ نداده (کنترل مثبت هم ناموفق)
| # | علت | تشخیص | اقدام |
| :--- | :--- | :--- | :--- |
| ۱ | **تحویل ناموفق** (شایع‌ترین) | کنترل ترانسفکشن/نوکلئوفکشن با پلاسمید **GFP** ← درصد مثبت را بسنجید (فصل ۱۵) | برنامه‌ی نوکلئوفکشن و بافر مخصوص همان رده؛ در تحویل پلاسمیدی، نسبت DNA به معرف را بهینه کنید |
| ۲ | **sgRNA تخریب‌شده** | یکپارچگی RNA را بسنجید؛ sgRNA از الیکوت تازه امتحان کنید | کار **RNase-free**؛ الیکوت تک‌مصرف؛ sgRNA **سنتتیک با تغییرات پایدارکننده** |
| ۳ | **Cas9 غیرفعال** | الیکوت تازه؛ ترجیحاً Lot دیگر | ❗ ذوب-انجماد مکرر پروتئین را خراب می‌کند |
| ۴ | **RNP تشکیل نشده** | ترتیب و زمان انکوباسیون را بازبینی کنید | sgRNA را اول رقیق، بعد Cas9 را اضافه؛ 🔎 ۱۰–۲۰ دقیقه دمای اتاق؛ **ورتکس نکنید** |
| ۵ | **سازه‌ی پلاسمیدی غلط** | ❗ **توالی‌یابی سنگر با پرایمر U6** | راهنما ممکن است درج نشده یا جهش‌دار باشد — پیش از هر آزمایش تأیید کنید |
| ۶ | **سلول نامناسب** | زیستایی، پاساژ، آلودگی **مایکوپلاسما** (فصل ۱۵) | کشت سالم با زیستایی بالای ۹۰٪؛ رده‌ی تازه از بانک |
| ۷ | **آمپلیکون/سنجش اشتباه** | آیا پرایمرها ناحیه‌ی درست را تکثیر می‌کنند؟ | پرایمرها را با توالی مرجع تطبیق دهید؛ محصول را توالی‌یابی کنید |

## ۲. کنترل مثبت کار می‌کند، اما راهنمای من نه
| علت | اقدام |
| :--- | :--- |
| **راهنمای کم‌بازده** (شایع‌ترین؛ پیش‌بینی ابزارها قطعی نیست) | 🔎 **۳ تا ۴ راهنمای مستقل** را موازی امتحان کنید — راه‌حل اصلی همین است |
| **PAM یا توالی هدف در این رده متفاوت است** (چندشکلی/واریانت رده) | ناحیه‌ی هدف را **در همان رده توالی‌یابی** کنید؛ ❗ یک SNP در ناحیه‌ی بذر، راهنما را از کار می‌اندازد |
| **کروماتین بسته/ناحیه‌ی غیرقابل‌دسترس** | راهنمایی در ناحیه‌ی دیگر همان اگزون؛ یا هدف‌گیری اگزون دیگر |
| **توالی TTTT در راهنما** | رونوشت U6 **زودتر پایان می‌یابد** ← راهنما را عوض کنید |
| **رونوشت U6 با G شروع نمی‌شود** | یک **G** به ابتدا بیفزایید |
| **ژن چندنسخه‌ای/پاراالوگ یا رده‌ی پلی‌پلوئید** | ویرایش همه‌ی نسخه‌ها لازم است ← انتظار درصد پایین‌تر؛ کلون‌های بیشتری غربال کنید |

## ۳. ویرایش هست ولی درصد پایین است
| محور | اقدام |
| :--- | :--- |
| **راهنما** | راهنمای بهتر؛ موازی‌سازی چند راهنما |
| **دوز و نسبت** | 🔎 نسبت Cas9:sgRNA = ۱:۱٫۲؛ افزایش دوز RNP **به‌تدریج** (❗ دوز زیاد = سمیت و آف‌تارگت) |
| **زمان برداشت** | 🔎 **۴۸ تا ۷۲ ساعت**؛ خیلی زود = کم‌برآورد |
| **قالب تحویل** | RNP ← کارایی و گذرا بودن بهتر؛ در تحویل پلاسمیدی، **انتخاب با پورومایسین** جمعیت را غنی می‌کند |
| **غنی‌سازی** | انتخاب دارویی، یا **سورت سلول‌های گزارشگر-مثبت** (فصل ۱۵) |
| **سنجش** | ❗ اگر با **T7E1** سنجیده‌اید، عدد **کم‌برآورد** است ← با **سنگر/TIDE** یا **NGS آمپلیکونی** بسنجید |
| **پلیمراز آمپلیکون** | **High-Fidelity** (پلیمراز معمولی ایندل کاذب می‌سازد) |

## ۴. مرگ سلولی پس از تحویل
| علت | تشخیص | اقدام |
| :--- | :--- | :--- |
| **سمیت پالس الکتریکی** | کنترل **Mock** (پالس بدون RNP) هم می‌میرد | برنامه‌ی ملایم‌تر؛ سلول کمتر در کووت؛ محیط گرم و از پیش آماده برای بازیابی |
| **دوز بالای RNP** | Mock سالم، نمونه می‌میرد | کاهش دوز؛ 🔎 نسبت و حجم را کم کنید |
| **پاسخ ایمنی ذاتی به RNA** | با sgRNA رونویسی‌شده‌ی درون‌شیشه‌ای بیشتر است | **sgRNA سنتتیک با تغییرات شیمیایی**؛ هضم DNase و خالص‌سازی کامل الگو |
| **ژن هدف ضروری است** | مرگ **انتخابی** در راهنماهای هدف، نه در راهنمای بدون هدف | سیستم **القایی** یا **CRISPRi** (خاموشی برگشت‌پذیر) به‌جای ناک‌اوت |
| **پاسخ p53 / توقف چرخه** | رشد کند پس از ویرایش | کاهش DSB: ویرایش **باز/پرایم**؛ دوز کمتر |
| **سمیت انتخاب دارویی** | مرگ در حین پورومایسین | **منحنی کشتار** همان رده (فصل ۱۵) |

## ۵. HDR / ناک-این نمی‌گیرد
| علت | اقدام |
| :--- | :--- |
| ❗ **برش مجدد محصول اصلاح‌شده** | در الگو **PAM را خراب کنید** یا **جهش خاموش** در توالی راهنما بگذارید |
| **بازوی همولوگ کوتاه** | 🔎 **۴۰ تا ۶۰ nt** در هر طرف برای ssODN؛ برای درج بزرگ، بازوهای بلندتر و پلاسمید |
| **فاصله‌ی زیاد برش از محل تغییر** | 🔎 برش را **تا ~۱۰ تا ۲۰ bp** محل تغییر نزدیک کنید |
| **سلول تقسیم‌نشونده** | HDR فقط در **S/G2**؛ سلول‌های در تقسیم فعال؛ (🔎 در برخی رده‌ها هم‌زمان‌سازی چرخه کمک می‌کند) |
| **الگوی ناکافی/ناخالص** | 🔎 ~۱۰۰ pmol ssODN؛ الیگوی **HPLC-خالص** |
| **سنجش نامناسب** | ❗ **T7E1/TIDE، HDR را نشان نمی‌دهد** ← توالی‌یابی، PCR اختصاصی آلل، یا هضم تشخیصی |
| **انتظار غیرواقعی** | بازده HDR معمولاً **چند مرتبه** کمتر از NHEJ ← کلون‌های بیشتری غربال کنید، یا به **ویرایش پرایم/باز** تغییر دهید |

## ۶. مشکلات کلون و تأیید
| مشاهده | علت | اقدام |
| :--- | :--- | :--- |
| **کروماتوگرام کلون برهم‌نهاده است** | دو **آلل متفاوت** (طبیعی)، یا چاهک **دوکلونی** | آمپلیکون را در **وکتور TA** کلون و چند کلنی را جدا توالی‌یابی کنید (فصل ۱۴)، یا **NGS آمپلیکونی**؛ چاهک‌های دوکلونی را حذف کنید |
| **DNA ویرایش‌شده ولی پروتئین باقی است** | ⚠️ **ایندل درون‌فریم**؛ یا **شروع از ATG بعدی**؛ یا جهش‌گریزی اسپلایسینگ | توالی هر آلل را بخوانید؛ آنتی‌بادی علیه ناحیه‌ی دیگر (C-ترمینال) هم بزنید؛ راهنمای اگزون دیگر |
| **وسترن ضعیف‌تر اما نه صفر** | جمعیت مخلوط؛ یا ناک‌داون جزئی | کلون تک؛ ❗ «ناک‌اوت» را فقط با **توالی آلل‌ها + پروتئین صفر** ادعا کنید |
| **فنوتیپ بین کلون‌ها متفاوت است** | **تنوع کلونال** (مستقل از ویرایش) | 🔎 **حداقل دو کلون مستقل**، ترجیحاً از **راهنماهای مختلف**؛ کلون‌های کنترل (راهنمای بدون هدف) هم جدا کنید |
| **رده با پاساژ بالا فنوتیپ را از دست می‌دهد** | انتخاب جمعیتی/بی‌ثباتی | **بانک سلولی از پاساژ پایین** (فصل ۱۵)؛ پایش دوره‌ای |
| **حذف بزرگ یا بازآرایی پیش‌بینی‌نشده** | DSB می‌تواند حذف‌های بزرگ بسازد | PCR با پرایمرهای **دورتر**؛ در موارد مهم، بررسی عدد کپی |

## ۷. آف‌تارگت و فنوتیپ مشکوک
| وضعیت | اقدام |
| :--- | :--- |
| فنوتیپ قوی اما **غیرمنتظره** | ⚠️ اول **آف‌تارگت** و **تنوع کلونال** را رد کنید، نه این‌که کشف جدید اعلام کنید |
| اثبات اختصاصی بودن فنوتیپ | **نجات (Rescue)**: بیان مجدد ژن مقاوم به راهنما (cDNA بدون PAM/با جهش خاموش) ← فنوتیپ باید **برگردد** — قوی‌ترین شاهد |
| تأیید مستقل | **چند راهنمای مستقل** با فنوتیپ یکسان |
| سنجش آف‌تارگت | جایگاه‌های محتمل: **سنگر/NGS آمپلیکونی**؛ در صورت لزوم روش کشف بی‌طرف |
| کاهش آف‌تارگت | **RNP** به‌جای پلاسمید؛ **Cas9 پراختصاص**؛ **نیکاز جفت‌شده**؛ راهنمای کوتاه‌شده؛ کمترین دوز مؤثر |
| گزارش | ❗ فهرست جایگاه‌های بررسی‌شده و روش را ذکر کنید؛ «اختصاصی» بدون سنجش، ادعای بی‌پشتوانه است |

## ۸. سنجش تشخیصی (RPA + Cas12a/Cas13a)
### ۸.۱. مثبت کاذب
| علت | نشانه | اقدام |
| :--- | :--- | :--- |
| ⚠️ **آلودگی آمپلیکون** (مشکل اصلی) | **NTC مثبت**، به‌ویژه پس از چند ران موفق | **سه فضای جدا** و جهت یک‌طرفه (فصل ۰۷)؛ معرف و پیپت تازه؛ تمیزکاری سطوح؛ ران باطل |
| **تخریب خودبه‌خودی گزارشگر** | کنترل «فقط گزارشگر» سیگنال بالا دارد | گزارشگر تازه؛ دور از نور؛ بافر RNase/DNase-free |
| **تکثیر غیراختصاصی RPA** | NTC در ژل باند/اسمیر دارد | پرایمرهای RPA را بازطراحی کنید؛ 🔎 زمان تکثیر را کم کنید |
| **فعالیت جانبی ناشی از crRNA ناقص** | سیگنال در نمونه‌های منفی | crRNA تازه و خالص؛ کنترل **بدون هدف** |

### ۸.۲. منفی کاذب / بدون سیگنال
| علت | اقدام |
| :--- | :--- |
| **تکثیر RPA انجام نشده** | محصول را روی ژل ببینید؛ کنترل مثبت؛ 🔎 دما ۳۷–۴۲°C و زمان کافی؛ پرایمر بازطراحی |
| **مهارکننده در نمونه** | رقیق کردن نمونه؛ استخراج ستونی؛ **کنترل داخلی** |
| **crRNA نامناسب برای این هدف** | طراحی crRNA دیگر؛ تطبیق با توالی واریانت‌ها |
| **Cas یا گزارشگر غیرفعال** | الیکوت تازه؛ کنترل مثبت نزدیک **LOD** |
| **دما/زمان قرائت** | 🔎 ۳۷°C و پایش **سینتیک** ۳۰–۶۰ دقیقه‌ای (نه یک قرائت نقطه‌ای) |
| **هدف RNA تخریب‌شده** | کار RNase-free؛ RT سالم؛ زنجیره‌ی سرد نمونه (فصل ۰۳) |

### ۸.۳. مشکلات تفسیر و اعتبارسنجی
| خطا | کار درست |
| :--- | :--- |
| کمی‌سازی از شدت فلورسانس | ❗ روش عمدتاً **کیفی** است ← برای کمی‌سازی **qPCR** (فصل ۰۸) |
| آستانه‌ی خوانده‌شده **پس از دیدن نتایج** | آستانه را از **NTC و تکرارها** و **پیش از** تحلیل تعیین کنید |
| خواندن نوار جریان جانبی بدون دفترچه | ❗ منطق خط تست/کنترل در برخی قالب‌ها **معکوس** است |
| استفاده‌ی بالینی بدون اعتبارسنجی | ⚠️ **LOD، اختصاصیت، تکرارپذیری و مقایسه با روش مرجع** لازم است |

## ۹. ⚠️ ایمنی، اخلاق و مسائل اداری
| مورد | اقدام |
| :--- | :--- |
| پروژه بدون **مجوز کمیته‌ی ایمنی زیستی/اخلاق** | ⛔ کار را شروع نکنید؛ مجوز مقدم بر هر بهینه‌سازی فنی است |
| ⛔ درخواست ویرایش **زاینده‌ی انسانی** یا جنین | **خارج از محدوده‌ی این مخزن**؛ موضوع را به کمیته‌ی اخلاق مؤسسه ارجاع دهید |

| سلول/نمونه‌ی انسانی | رضایت و منشأ مستند |
| ثبت و شفافیت | توالی راهنماها، سازه‌ها، نتایج آف‌تارگت و نسخه‌ی ابزارها را ثبت و در انتشار گزارش کنید |
