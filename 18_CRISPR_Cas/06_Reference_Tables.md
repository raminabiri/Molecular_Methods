# ۱۸ — جداول مرجع CRISPR-Cas

> ⚠️ عددهای **🔎** را با **دفترچه‌ی همان محصول/کیت** و پروتکل مرجع (Ran و همکاران، ۲۰۱۳) تأیید کنید.
> ⛔ **ویرایش زاینده‌ی انسانی، جنین و گِین-درایو خارج از محدوده‌ی این مخزن است.**

---

## جدول ۱ — فرمول‌ها و محاسبات
| کمیت | فرمول |
| :--- | :--- |
| جرم از مول | $m = n \times M$ (SpCas9 ≈ **۱۶۰ kDa**؛ هر نوکلئوتید RNA ≈ **۳۲۵ Da**) |
| نسبت RNP | **Cas9 : sgRNA = ۱ : ۱٫۲** (مولی) |
| حجم از استوک مولار | $V = n / C$ (۱۰۰ µM = ۱۰۰ pmol/µL) |
| فراوانی PAM (NGG، دو رشته) | $\approx \tfrac{1}{8}$ ← هر **~۸ bp** یک PAM |
| سلول‌های بدون ویرایش | $(1-p)^2$ |
| سلول‌های دوآللی ویرایش‌شده | $p^2$ |
| ناک‌اوت دوآللی با تغییر قالب | $(\tfrac{2}{3}p)^2$ |
| تعداد کلون برای اطمینان ۹۵٪ | $n = \dfrac{\ln 0{,}05}{\ln(1-f)}$ ($f$ = نرخ کلون مطلوب) |
| پوشش کتابخانه | $N_{\text{سلول}} = N_{\text{راهنما}} \times \text{پوشش}$ |
| سلول لازم برای ترانسداکشن | $N_{\text{سلول}} / \text{کارایی}$ |
| پواسون در MOI پایین | $P(k) = \dfrac{\lambda^k e^{-\lambda}}{k!}$ (MOI = ۰٫۳ ← ~۸۶٪ سلول‌های آلوده تک‌نسخه) |

## جدول ۲ — مقایسه‌ی نوکلئازها
| ویژگی | **Cas9 (SpCas9)** | **Cas12a (Cpf1)** | **Cas13a** |
| :--- | :--- | :--- | :--- |
| هدف | DNA دورشته | DNA دورشته | **RNA** |
| راهنما | crRNA + tracrRNA (**sgRNA**) | **فقط crRNA** | crRNA |
| PAM/PFS | **۵'-NGG-3'** (سمت ۳') | **غنی از T** مانند TTTV (سمت ۵') | بدون PAM |
| محل برش | 🔎 ~**۳ bp** بالادست PAM | دورتر از PAM | روی RNA |
| نوع برش | **صاف** | **پله‌ای** (آویزان ۵') | برش RNA |
| فعالیت جانبی | — | **ssDNase** | **RNase** |
| کاربرد شاخص | ویرایش عمومی | ویرایش؛ **DETECTR** | **SHERLOCK** |

## جدول ۳ — نسخه‌های مهندسی‌شده و فناوری‌های مشتق
| نسخه | تغییر | کاربرد |
| :--- | :--- | :--- |
| **nCas9** | یک دومین غیرفعال (D10A) | نیکاز جفت‌شده؛ پایه‌ی ویرایشگرهای باز و پرایم |
| **dCas9** | D10A + H840A | **CRISPRi/a**، ویرایش اپی‌ژنتیک، تصویربرداری |
| **eSpCas9 / SpCas9-HF1** | کاهش تماس غیراختصاصی با اسکلت DNA | **کاهش آف‌تارگت** |
| **SaCas9 و نسخه‌های PAM-تغییریافته** | PAM متفاوت، اندازه‌ی کوچک‌تر | دسترسی به اهداف بدون NGG؛ بسته‌بندی در **AAV** |
| **CBE** | nCas9 + سیتیدین دآمیناز + **UGI** | **C→T** |
| **ABE** | nCas9 + TadA مهندسی‌شده | **A→G** |
| **ویرایش پرایم** | nCas9 + رورس ترانسکریپتاز + **pegRNA** | هر تغییر کوچک، بدون DSB و بدون الگوی جدا |
| **CRISPRi / CRISPRa** | dCas9 + KRAB / فعال‌کننده | خاموشی برگشت‌پذیر / فعال‌سازی |

## جدول ۴ — قواعد طراحی sgRNA
| معیار | قاعده | دلیل |
| :--- | :--- | :--- |
| PAM | **NGG** در موقعیت درست | بدون PAM برشی نیست |
| طول فاصله‌گذار | 🔎 **۲۰ nt** | استاندارد SpCas9 |
| موقعیت (ناک‌اوت) | اگزون **ابتدایی و مشترک همه‌ی آیزوفرم‌ها** (🔎 ۵–۶۵٪ ابتدای ORF) | کدون پایان زودرس؛ پوشش همه‌ی آیزوفرم‌ها |
| موقعیت (ناک-این) | 🔎 تا **۱۰–۲۰ bp** از محل تغییر | بازده HDR با فاصله افت می‌کند |
| GC | 🔎 **۴۰–۶۰٪** | پایداری اتصال بدون ساختار ثانویه |
| توالی ممنوع | ❗ **TTTT** و بیشتر | **ترمیناتور پلیمراز III** |
| شروع رونوشت U6 | با **G** | بازده رونویسی |
| اختصاصیت | کمترین جایگاه مشابه، **بذر منحصربه‌فرد** | ناجوری انتهای ۵' تحمل می‌شود ← آف‌تارگت |
| تعداد | 🔎 **۳–۴ راهنما برای هر ژن** | بازده راهنماها پیش‌بینی‌ناپذیر است |
| کنترل | **راهنمای بدون هدف** + **کنترل مثبت اثبات‌شده** | تفکیک اثر اختصاصی از غیراختصاصی |

## جدول ۵ — روش‌های تحویل
| قالب | مدت مواجهه | آف‌تارگت | DNA خارجی | کِی |
| :--- | :--- | :--- | :--- | :--- |
| **RNP** | **گذرا (ساعت)** | **کمترین** | ندارد | **انتخاب ترجیحی**؛ با نوکلئوفکشن |
| mRNA + sgRNA | گذرا | کم | ندارد | سلول‌های حساس |
| **پلاسمید** | **طولانی (روز–هفته)** | **بیشتر** | دارد (خطر درج تصادفی) | رده‌های آسان؛ ارزان؛ با انتخاب پورومایسین |
| **لنتی‌ویروس** | پایدار | بیشتر | ادغام می‌شود | **کتابخانه‌ی غربالگری**؛ ⚠️ BSL-2 تشدیدشده |
| **AAV** | طولانی | — | عمدتاً اپیزومی | کاربرد درون‌تنی؛ ظرفیت ~۴٫۷ kb |
> ارجاع: فصل ۱۵ برای نوکلئوفکشن، لنتی‌ویروس و AAV.

## جدول ۶ — 🔎 مقادیر نمونه‌وار RNP و نوکلئوفکشن
| جزء | مقدار (برای 🔎 ۲×۱۰⁵ سلول) |
| :--- | :--- |
| Cas9 پروتئین | **۶۰ pmol** (≈ **۹٫۶ µg**) |
| sgRNA | **۷۲ pmol** (sgRNA ۱۰۰ nt ≈ **۲٫۳۴ µg**) |
| انکوباسیون تشکیل کمپلکس | **۱۰–۲۰ دقیقه، دمای اتاق** |
| الگوی HDR (ssODN) | 🔎 ~**۱۰۰ pmol**؛ بازوی **۴۰–۶۰ nt** هر طرف |
| برداشت DNA | **۴۸–۷۲ ساعت** پس از تحویل |
> ترتیب: sgRNA را رقیق کنید، **سپس** Cas9 را اضافه کنید؛ **ورتکس نکنید**. ❗ برای دقت نسبت، **رقت کاری** یا **مسترمیکس RNP** بسازید.

## جدول ۷ — روش‌های اعتبارسنجی ویرایش
| روش | چه می‌گوید | محدودیت کلیدی |
| :--- | :--- | :--- |
| **سنگر + TIDE/ICE** | **درصد و طرح ایندل** در جمعیت | ایندل بزرگ و فراوانی کم؛ نیازمند آمپلیکون با طراحی درست |
| **T7E1** | برآورد سریع و **کیفی** | ❗ ایندل **یکسان دوآللی** را نمی‌بیند (**کم‌برآورد**)؛ مثبت کاذب با SNP؛ HDR را نشان نمی‌دهد |
| **NGS آمپلیکونی** | **دقیق‌ترین** کمی + آف‌تارگت هدف‌دار | هزینه؛ 📌 تحلیل در مخزن دیگر |
| **ژنوتایپینگ کلون تک** | توالی **هر آلل** | زمان‌بر؛ اجباری برای ساخت رده |
| **وسترن** (فصل ۱۱) | حذف **پروتئین** | ⚠️ ایندل درون‌فریم یا شروع از ATG بعدی |
| **RT-qPCR** (فصل ۰۸) | سطح mRNA | mRNA و پروتئین همیشه هم‌راستا نیستند |
| **آزمون نجات (Rescue)** | **علیت** فنوتیپ | cDNA باید **مقاوم به راهنما** باشد |
> **شرط طراحی آمپلیکون سنگر:** 🔎 محل برش **≥۲۰۰ bp** پس از شروع خوانش و **≥۱۰۰ bp** توالی باکیفیت پس از آن.

## جدول ۸ — آف‌تارگت: سنجش و کاهش
| اقدام | توضیح |
| :--- | :--- |
| **سنجش هدف‌دار** | جایگاه‌های محتمل (🔎 تا ۳–۴ ناجوری) ← PCR + **سنگر/NGS آمپلیکونی** |
| **کشف بی‌طرف** | GUIDE-seq و روش‌های مبتنی بر ژنوم (پژوهشی، پرهزینه) |
| **RNP به‌جای پلاسمید** | کوتاه کردن **مدت مواجهه** |
| **Cas9 پراختصاص** | eSpCas9، SpCas9-HF1 |
| **نیکاز جفت‌شده** | دو nCas9 + دو راهنما ← DSB فقط در محل همپوشانی |
| **راهنمای کوتاه‌شده** | کاهش حاشیه‌ی تحمل ناجوری |
| **کمترین دوز مؤثر** | آف‌تارگت وابسته به دوز و زمان است |
| **چند راهنمای مستقل** | فنوتیپ مشترک = بعید است حاصل آف‌تارگت باشد |
> ❗ ادعای «ویرایش اختصاصی» بدون **فهرست جایگاه‌های بررسی‌شده و روش**، بی‌پشتوانه است.

## جدول ۱۰ — سنجش‌های تشخیصی
| مورد | **DETECTR** | **SHERLOCK** |
| :--- | :--- | :--- |
| آنزیم | **Cas12a** | **Cas13a** |
| هدف | **DNA** | **RNA** |
| تکثیر پیش‌نیاز | **RPA** | **RT-RPA** |
| گزارشگر | **ssDNA**-FQ یا FAM-بیوتین | **ssRNA**-FQ یا FAM-بیوتین |
| 🔎 شرایط | ۳۷°C؛ تکثیر **۲۰–۳۰ دقیقه**؛ قرائت **۳۰–۶۰ دقیقه** با بازه‌ی ۳۰ ثانیه–۱ دقیقه | همان |
| قرائت | فلورسانس (**سینتیک**) یا **نوار جریان جانبی ۲–۵ دقیقه** | همان |
| خروجی | **کیفی** | **کیفی** |
> **کنترل‌های اجباری:** **NTC** · **بدون crRNA** · **فقط گزارشگر** · **کنترل مثبت نزدیک LOD**.
> ⚠️ **آلودگی آمپلیکون** خطر اصلی ← **سه فضای جدا**، جهت یک‌طرفه، نوک فیلتردار (فصل ۰۷).
> برای **کمی‌سازی**: **qPCR** (فصل ۰۸).

## جدول ۱۱ — الزامات اعتبارسنجی پیش از استفاده‌ی تشخیصی
| الزام | توضیح |
| :--- | :--- |
| **LOD** | سری رقت + تکرار کافی؛ تعریف: کمترین غلظت مثبت در **≥۹۵٪** تکرارها |
| **اختصاصیت تحلیلی** | اهداف نزدیک، واکنش متقاطع، نمونه‌های منفی شناخته |
| **تکرارپذیری** | درون-ران، بین-ران، بین-اپراتور، بین-Lot |
| **مقاومت به مهار** | ماتریکس واقعی نمونه + **کنترل داخلی** |
| **اعتبارسنجی بالینی** | مقایسه با روش مرجع ← حساسیت/ویژگی بالینی |
| **سیستم کیفیت** | SOP، آموزش، کنترل کیفی خارجی، مدیریت Lot، مستندسازی |
| **وضعیت قانونی معرف‌ها** | ❗ بسیاری از اجزای CRISPR **RUO/پژوهشی**‌اند، نه IVD |

## جدول ۱۲ — ⚠️ ایمنی، اخلاق و محدوده
| موضوع | وضعیت |
| :--- | :--- |
| کشت سلول | **BSL-2**، کابینت کلاس II |
| لنتی‌ویروس/AAV | **BSL-2 تشدیدشده**؛ همه‌ی الزامات فصل ۱۵ (اجسام تیز ممنوع، سطل دربسته) |
| جدایه‌های بالینی مقاوم | BSL-2 یا بالاتر؛ مجوز کمیته‌ی ایمنی زیستی |
| ⛔ **ویرایش زاینده‌ی انسانی / جنین** | **خارج از محدوده‌ی این مخزن** |
| ⛔ **گِین-درایو / افزایش حدت** | **خارج از محدوده** |
| ویرایش سوماتیک درمانی | فقط با مجوز رسمی و نظارت اخلاقی؛ خارج از محدوده‌ی پروتکل‌های این فصل |
| سلول/نمونه‌ی انسانی | رضایت و منشأ مستند |
| کاربرد دوگانه | ارزیابی و رد صریح در طرح پژوهشی |
| ثبت و شفافیت | توالی راهنماها، سازه‌ها، نتایج آف‌تارگت، نسخه‌ی ابزارها |
> ⚠️ **مجوز کمیته‌ی ایمنی زیستی و اخلاق پیش از شروع؛ دستورالعمل مؤسسه مقدم است.**

## جدول ۱۳ — عیب‌یابی سریع
| مشاهده | علت اول |
| :--- | :--- |
| هیچ ویرایشی، کنترل مثبت هم ناموفق | **تحویل** (با کنترل GFP بسنجید) |
| هیچ ویرایشی، کنترل مثبت موفق | **راهنمای کم‌بازده** یا SNP در هدف |
| درصد ویرایش پایین | راهنما؛ دوز؛ زمان برداشت؛ سنجش T7E1 |
| Mock هم می‌میرد | **سمیت پالس** |
| فقط نمونه می‌میرد | دوز RNP؛ پاسخ به RNA؛ **ژن ضروری** |
| HDR صفر | ❗ **برش مجدد** (PAM خراب نشده) |
| کروماتوگرام کلون برهم‌نهاده | دو آلل متفاوت یا چاهک دوکلونی |
| DNA ویرایش‌شده، پروتئین باقی | **ایندل درون‌فریم** یا ATG بعدی |
| فنوتیپ غیرمنتظره | آف‌تارگت یا **تنوع کلونال** ← **آزمون نجات** |
| NTC سنجش تشخیصی مثبت | **آلودگی آمپلیکون** |
| سنجش روی نمونه‌ی بالینی منفی | **مهار** یا واریانت توالی |
