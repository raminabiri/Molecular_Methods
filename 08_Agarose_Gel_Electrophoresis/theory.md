# مرجع جامع تئوری، الگوریتم‌ها و روش‌های آنالیز qPCR (Real-Time PCR)

### ۱.۱. منحنی تکثیر (Amplification Curve) و فازهای آن

در تکنیک Real-Time PCR، میزان تکثیر محصول در طی هر سیکل از طریق ثبت سیگنال فلورسانس پایش می‌شود. یک منحنی تکثیر استاندارد شامل ۴ فاز اصلی است:

```
          |                                     / (فاز پلاتو / Plateau)
          |                                    /
          |                                   / (فاز خطی / Linear)
فلورسانس  |                                  /
  (Log)   |                                 / (فاز نمایی / Exponential)
          |  ------------------------------/ 
          | / (فاز خط پایه / Baseline)
          +---------------------------------------------------
                                 سیکل (Cycle)

```

1. **فاز خط پایه (Baseline Phase):** در سیکل‌های اولیه (معمولاً سیکل ۳ تا ۱۵)، سیگنال فلورسانس ناشی از تکثیر هنوز به حد تشخیص دستگاه نرسیده و معادل نویز محیطی یا فلورسانس زمینه است.

2. **فاز نمایی (Exponential Phase):** واکنش با راندمان نزدیک به ۱۰۰٪ انجام می‌شود و مقدار محصول در هر سیکل دو برابر می‌شود ($N = N_0 \times 2^n$). در این فاز، واکنش دارای بالاترین دقت و قابلیت بازتولید است و تمامی محاسبات کمی در این ناحیه صورت می‌گیرد.

3. **فاز خطی (Linear Phase):** با کاهش غلظت واکشن‌گرها (سابستریت، پرایمرها و آنزیم)، سرعت واکنش افت کرده و تکثیر خطی می‌شود.

4. **فاز پلاتو (Plateau Phase):** واکنش به علت تمام شدن مواد اولیه یا غیرفعال شدن آنزیم متوقف شده و سیگنال فلورسانس ثابت می‌ماند.

### ۱.۲. پارامترهای کلیدی در آنالیز کمی

* $C_t$ **(Cycle Threshold) یا** $C_q$ **(Quantification Cycle):** شماره سیکلی است که در آن منحنی فلورسانس نمونه از خط آستانه (Threshold) عبور می‌کند. $C_q$ نسبت معکوس با لوگاریتم غلظت اولیه الگو دارد.

* **Threshold (خط آستانه):** سطحی از فلورسانس است که بالاتر از نویز زمینه (Baseline) و دقیقاً در آغاز فاز نمایی تنظیم می‌شود.

* **Amplification Efficiency (**$E$**):** راندمان تکثیر نشان‌دهنده نسبت دو برابر شدن قطعه در هر سیکل است. راندمان نظری ۱۰۰٪ معادل $E = 2$ است:
  

  $$
  E = 10^{-1/\text{slope}}
  $$

  
  در حالت درصدی: $\text{Efficiency \%} = (E - 1) \times 100$

### ۲.۱. کمی‌سازی مطلق (Absolute Quantification)

در این روش، تعداد دقیق نسخه‌های اسید نوکلئیک (Copy Number) یا غلظت دقیق نمونه نامشخص در واحد حجم (مثلاً $\text{copies/\mu L}$) تعیین می‌شود.

* **مراحل اجرا:**

  1. ساخت یک استاندار با غلظت دقیقاً مشخص (پلاسمید حاوی ژن هدف یا محصول PCR خالص‌سازی‌شده).

  2. تهیه رقیق‌سازی‌های متوالی (Serial Dilutions) با فاکتور ۱۰ (مثلاً از $10^7$ تا $10^1$ نسخه).

  3. ترسیم **منحنی استاندارد (Standard Curve)** با محور X به عنوان $\log_{10}(\text{Copy Number})$ و محور Y به عنوان $C_q$.

  4. محاسبه تعداد نسخه‌های نمونه مجهول از روی معادله خط رگرسیون ($y = mx + b$):
     

     $$
     \text{Log}(\text{Copy Number}) = \frac{C_q - b}{m}
     $$

     $$
     \text{Copy Number} = 10^{\frac{C_q - b}{m}}
     $$

### ۲.۲. کمی‌سازی نسبی (Relative Quantification)

در این روش، تغییرات بیان یک ژن هدف در گروه‌های مختلف (مثلاً گروه تیمار در مقایسه با کنترل) سنجیده می‌شود و نیازی به تعیین تعداد دقیق نسخه‌ها نیست. روش‌های اصلی آن عبارتند از:

1. **روش** $2^{-\Delta \Delta C_t}$ **(روش Livak):** با فرض راندمان ۱۰۰٪ ($E=2$) برای ژن هدف و مرجع.

2. **روش Pfaffl:** با اعمال راندمان واقعی و اختصاصی هر پرایمر.

| پارامتر مقایسه‌ای | کمی‌سازی مطلق (Absolute) | کمی‌سازی نسبی (Relative) | 
| ----- | ----- | ----- | 
| **هدف** | تعیین تعداد دقیق نسخه‌ها (Copy Number) | تعیین ضریب تغییر بیان (Fold Change) | 
| **نیازمندی به منحنی استاندارد** | الزامی (برای هر سنجش) | غیراجباری (فقط برای تعیین راندمان) | 
| **کاربردها** | بار ویروسی (Viral Load)، تعداد نسخه‌های ژن توموری | مطالعات بیان ژن، پاسخ به دارو، تمایز سلولی | 
| **نیاز به ژن مرجع** | خیر (اختیاری جهت کنترل کیفیت) | **بسیار حیاتی** (برای نرمالسازی) | 

### ۳.۱. تعریف و نقش نرمالایزر

نرمالایزر یا ژن مرجع (Housekeeping Gene)، ژنی است که بیان آن در تمامی سلول‌ها، بافت‌ها و تحت شرایط تجربی یا بیماری‌های مختلف ثابت باقی می‌ماند. نقش نرمالایزر خنثی‌کردن خطاهای ناشی از:

* تفاوت در میزان اولیه RNA وارد شده به واکنش سنتز cDNA.

* تفاوت در راندمان فرآیند Reverse Transcription (RT).

* وجود مهارکننده‌های احتمالی PCR در نمونه‌ها.

### ۳.۲. انواع نرمالایزرها و خصوصیات آن‌ها

1. $\beta$**-Actin (ACTB):**

   * **نقش:** پروتئین اصلی اسکلت سلولی.

   * **کاربرد:** سنجش‌های عمومی بیان ژن در سلول‌های پستانداران.

   * **محدودیت:** بیان آن در طی تغییرات ساختاری سلول، تهاجم سرطانی و تمایز سلولی تغییر می‌کند.

2. **GAPDH (Glyceraldehyde 3-phosphate dehydrogenase):**

   * **نقش:** آنزیم کلیدی مسیر گلیکولیز.

   * **کاربرد:** بافت‌های نرمال کبد، کلیه و سلول‌های بنیادی.

   * **محدودیت:** تحت شرایط هیپوکسی (کمبود اکسیژن)، دیابت و استرس متابولیک به‌شدت افزایش بیان می‌یابد.

3. **18S rRNA / 28S rRNA:**

   * **نقش:** اجزای ساختاری ریبوزوم.

   * **مزایا:** بیان بسیار بالا و پایداری فوق‌العاده در برابر تخریب.

   * **محدودیت:** عدم امکان استفاده هنگام استفاده از پروب‌های Oligo-dT برای سنتز cDNA؛ همچنین بیان بسیار بالای آن نسبت به mRNAهای هدف باعث عدم تعادل $C_q$ می‌شود.

4. **B2M (Beta-2-microglobulin) و RPL13A:**

   * **کاربرد:** بهترین گزینه‌ها برای مطالعات ایمونولوژی، سلول‌های خونی و سرطانی.

### ۳.۳. چگونگی کاربرد و الگوریتم‌های انتخاب بهترین نرمالایزر

استفاده از تنها یک ژن مرجع می‌تواند باعث خطای فاحش در آنالیز شود. استاندارد MIQE استفاده از **میانگین هندسی (Geometric Mean)** حداقل ۲ یا ۳ ژن مرجع را توصیه می‌کند.

#### روش‌های نرمالسازی چندگانه:

برای ترکیب $n$ ژن مرجع، $C_q$ مرجع از رابطه زیر به دست می‌آید:

$$
\text{Ref}_{\text{GeoMean}} = \sqrt[n]{C_{q, \text{Ref1}} \times C_{q, \text{Ref2}} \times \dots \times C_{q, \text{Ref}n}}
$$

#### نرم‌افزارهای سنجش پایداری نرمالایزر:

* **geNorm:** پایداری ژن‌ها را بر اساس انحراف معیار جفت‌بازها ($M$-value) سنجیده و حداقل تعداد ژن مرجع لازم ($V$-value) را تعیین می‌کند.

* **NormFinder:** واریانس درون‌گروهی و بین‌گروهی را برای یافتن پایدارترین ژن محاسبه می‌کند.

### ۴.۱. انواع سیستم‌های آشکارسازی فلورسانس

1. **رنگ‌های متصل‌شونده به DNA دو رشته‌ای (Intercalating Dyes):**

   * **نمونه:** SYBR Green I, EvaGreen.

   * **مکانیسم:** رنگ به شیار کوچک (Minor Groove) DNA دو رشته‌ای متصل شده و سیگنال می‌دهد.

   * **مزیت:** ارزان، عدم نیاز به طراحی پروب.

   * **عیب:** عدم امکان مالتی‌پلاکس واقعی؛ اتصال به محصولات غیراختصاصی و دایمر پرایمر (نیاز به آنالیز منحنی ذوب / Melt Curve).

2. **پروب‌های اختصاصی (Hydrolysis Probes / TaqMan):**

   * **مکانیسم:** پروب حاوی یک رنگ گزارشگر (Reporter) در سمت '5 و یک کوئنچر (Quencher) در سمت '3 است. در طی فاز بسط، فعالیت '5 به '3 اگزونوکلئازی آنزیم Taq Polymerase پروب را تخریب کرده و فلوروفور از کوئنچر جدا شده و نور ساطع می‌کند.

   * **مزیت:** اختصاصیت فوق‌العاده بالا و قابلیت مالتی‌پلاکس.

```
فاز اتصال پروب:   [Reporter]----(Probe)----[Quencher]   (خاموش)
                                 |
فاز تخریب (Taq):  [Reporter] *   |   [Quencher]       (روشن شدن فلورسانس)

```

### ۴.۲. انتخاب فلوروفورها و کوئنچرها در واکنش‌های Multiplex

در مالتی‌پلاکس (تکثیر هم‌زمان چند ژن در یک چاهک)، باید فلوروفورهایی انتخاب شوند که **تداخل طیفی (Spectral Overlap / Crosstalk)** آن‌ها حداقل باشد.

#### ماتریس ترکیب فلوروفورها بر اساس کانال‌های استاندارد دستگاه:

| کانال دستگاه | فلوروفور پیشنهادی (Reporter) | طول موج انگیزش / انتشار ($nm$) | کوئنچر مناسب (Quencher) | هدف متداول | 
| ----- | ----- | ----- | ----- | ----- | 
| **FAM Channel** | **FAM / Alexa 488** | 495 / 520 | BHQ-1 / MGB | ژن هدف اول (Target 1) | 
| **HEX / VIC Channel** | **HEX / VIC / JOE** | 535 / 556 | BHQ-1 | ژن مرجع (Housekeeping) | 
| **Texas Red / ROX** | **Texas Red / ROX / JUN** | 583 / 603 | BHQ-2 | ژن هدف دوم (Target 2) | 
| **Cy5 Channel** | **Cy5 / Quasar 670** | 648 / 668 | BHQ-2 / BHQ-3 | کنترل داخلی صحت واکنش (IPC) | 

#### قوانین طراحی مالتی‌پلاکس:

1. عدم تداخل طیف انتشاری رنگ‌ها (استفاده از فلوروفورهای مجزا).

2. استفاده از **Dark Quenchers** (مانند BHQ-1 و BHQ-2) که خود نور ساطع نمی‌کنند.

3. تنظیم غلظت پرایمرها: کاهش غلظت پرایمرهای ژن با بیان بالا (ژن مرجع) تا مانع تکثیر ژن‌های با بیان ضعیف نشود.

### ۵.۱. ساختار جداول و فرمول‌های محاسبه $2^{-\Delta \Delta C_t}$

فرمول‌های زیر بر اساس ساختار استاندارد داده‌های تکرارشده در اکسل تنظیم شده‌اند:

```
[A] Sample_ID | [B] Group | [C] Cq_Target | [D] Cq_Ref1 | [E] Cq_Ref2

```

#### فرمول‌های درج‌شده در اکسل (از سطر ۲ به بعد):

1. **محاسبه میانگین هندسی ژن‌های مرجع (ستون F):**

   ```
   =EXP(AVERAGE(LN(D2), LN(E2)))
   
   ```

2. **محاسبه** $\Delta C_q$ **(ستون G):**

   ```
   =C2 - F2
   
   ```

3. **محاسبه میانگین** $\Delta C_q$ **گروه کنترل (در خانه J2):**

   ```
   =AVERAGEIF(B2:B20, "Control", G2:G20)
   
   ```

4. **محاسبه** $\Delta \Delta C_q$ **(ستون H):**

   ```
   =G2 - $J$2
   
   ```

5. **محاسبه Fold Change /** $2^{-\Delta \Delta C_t}$ **(ستون I):**

   ```
   =POWER(2, -H2)
   
   ```

### ۵.۲. فرمول‌نویسی روش Pfaffl در اکسل (اصلاح راندمان)

اگر راندمان تکثیر ژن هدف $E_{\text{Target}} = 1.95$ و ژن مرجع $E_{\text{Ref}} = 1.90$ باشد:

1. **محاسبه** $\Delta C_q$ **هدف (کنترل - تیمار) در ستون F:**

   ```
   =$J$5 - C2    (که J5 میانگین Cq Target در گروه کنترل است)
   
   ```

2. **محاسبه** $\Delta C_q$ **مرجع (کنترل - تیمار) در ستون G:**

   ```
   =$J$6 - D2    (که J6 میانگین Cq Ref در گروه کنترل است)
   
   ```

3. **محاسبه نسبت Pfaffl (ستون H):**

   ```
   =POWER(1.95, F2) / POWER(1.90, G2)
   
   ```

### ۶.۱. تئوری کارکرد LinRegPCR

نرم‌افزار LinRegPCR بر خلاف روش‌های سنتی که راندمان را از منحنی استاندارد سریال می‌سنجند، **راندمان تکثیر تک‌تک چاهک‌ها** را مستقیم از روی داده‌های خام فلورسانس (Raw Fluorescence Data) استخراج می‌کند.

### ۶.۲. مراحل گام‌به‌گام آنالیز در LinRegPCR:

1. **خروجی داده خام:** صادرات داده‌های فلورسانس هر سیکل از دستگاه qPCR به صورت اکسل.

2. **بارگذاری (Import):** وارد کردن فایل داده‌ها در LinRegPCR.

3. **تصحیح خط پایه (Baseline Correction):** نرم‌افزار الگوریتم غیرخطی بازسازی Baseline را اعمال می‌کند.

4. **تعیین Window of Linearity (WOL):** نرم‌افزار فاز نمایی واقعی را مشخص کرده و خط رگرسیون را بر نمودار $\log(\text{Fluorescence})$ رسم می‌کند.

5. **محاسبه** $E$ **و** $N_0$**:**

   * شیب خط منطبق‌شده ($m$) راندمان چاهک را تعیین می‌کند ($E = 10^m$).

   * فلورسانس اولیه الگو ($N_0$) پیش از شروع تکثیر محاسبه می‌شود.

6. **خروجی:** دریافت فایل اکسل حاوی $C_q$ و $E$ برای استفاده مستقیم در فرمول Pfaffl در R یا Excel.

کد زیر یک خط لوله تمام‌عیار برای دریافت داده‌های خام، پیش‌پردازش، محاسبه بیان نسبی، تست‌های آماری و رسم نمودار با کیفیت انتشاراتی (Publication-Ready) است.

```
# ==============================================================================
# خط لوله جامع آنالیز qPCR در زبان R
# ==============================================================================

# ۱. نصب و فراخوانی کتابخانه‌های لازم
if (!requireNamespace("BiocManager", quietly = TRUE)) install.packages("BiocManager")
packages <- c("tidyverse", "ggpubr", "rstatix", "RColorBrewer")
new_packages <- packages[!(packages %in% installed.packages()[,"Package"])]
if(length(new_packages)) install.packages(new_packages)

library(tidyverse)
library(ggpubr)
library(rstatix)
library(RColorBrewer)

# ------------------------------------------------------------------------------
# ۲. ساخت داده‌های خام آزمایشی (Simulated Data) جهت شبیه‌سازی
# ------------------------------------------------------------------------------
set.seed(123)

qpcr_raw <- data.frame(
  Sample_ID = rep(paste0("Sample_", 1:15), each = 3),
  Group = rep(c("Control", "Treated_DrugA", "Treated_DrugB"), each = 15),
  Cq_p53 = c(
    rnorm(15, mean = 25.2, sd = 0.25),  # Control
    rnorm(15, mean = 21.8, sd = 0.30),  # Drug A (Up-regulated)
    rnorm(15, mean = 27.1, sd = 0.28)   # Drug B (Down-regulated)
  ),
  Cq_GAPDH = rnorm(45, mean = 18.0, sd = 0.15),
  Cq_ACTB  = rnorm(45, mean = 19.2, sd = 0.18)
)

# ------------------------------------------------------------------------------
# ۳. پردازش داده‌ها و محاسبات Fold Change (روش Livak با چند ژن مرجع)
# ------------------------------------------------------------------------------
analyzed_data <- qpcr_raw %>%
  # میانگین‌گیری از تکرارهای فنی (Technical Replicates)
  group_by(Sample_ID, Group) %>%
  summarise(
    Mean_Cq_Target = mean(Cq_p53, na.rm = TRUE),
    Mean_Cq_Ref1   = mean(Cq_GAPDH, na.rm = TRUE),
    Mean_Cq_Ref2   = mean(Cq_ACTB, na.rm = TRUE),
    .groups = "drop"
  ) %>%
  # محاسبه میانگین هندسی نرمالایزرها
  mutate(
    Ref_GeoMean = sqrt(Mean_Cq_Ref1 * Mean_Cq_Ref2),
    Delta_Cq = Mean_Cq_Target - Ref_GeoMean
  )

# محاسبه میانگین Delta Cq در گروه کنترل
control_baseline <- analyzed_data %>%
  filter(Group == "Control") %>%
  summarise(mean_ctrl = mean(Delta_Cq)) %>%
  pull(mean_ctrl)

# محاسبه Delta Delta Cq و Fold Change
final_df <- analyzed_data %>%
  mutate(
    Delta_Delta_Cq = Delta_Cq - control_baseline,
    Fold_Change = 2^(-Delta_Delta_Cq)
  )

# ------------------------------------------------------------------------------
# ۴. تحلیل آمار استنباطی (آزمون‌های آماری روی Delta Cq)
# ------------------------------------------------------------------------------
# الف) بررسی نرمال بودن (Shapiro-Wilk)
normality_test <- final_df %>%
  group_by(Group) %>%
  shapiro_test(Delta_Cq)
print(normality_test)

# ب) آزمون ANOVA یک‌طرفه
anova_result <- final_df %>%
  anova_test(Delta_Cq ~ Group)
print(anova_result)

# ج) تست تعقیبی توکی (Tukey HSD)
stat_pvals <- final_df %>%
  tukey_hsd(Delta_Cq ~ Group) %>%
  add_significance() %>%
  add_xy_position(x = "Group")

# ------------------------------------------------------------------------------
# ۵. رسم نمودار انتشاراتی (Publication-Quality Plot)
# ------------------------------------------------------------------------------
# خلاصه آمار گروهی برای رسم نمودار
plot_summary <- final_df %>%
  group_by(Group) %>%
  summarise(
    Mean_FC = mean(Fold_Change),
    SEM_FC  = sd(Fold_Change) / sqrt(n()),
    .groups = "drop"
  )

main_plot <- ggplot(plot_summary, aes(x = Group, y = Mean_FC, fill = Group)) +
  geom_bar(stat = "identity", width = 0.55, color = "black", linewidth = 0.7, alpha = 0.85) +
  geom_errorbar(aes(ymin = Mean_FC - SEM_FC, ymax = Mean_FC + SEM_FC),
                width = 0.18, linewidth = 0.8) +
  geom_jitter(data = final_df, aes(x = Group, y = Fold_Change),
              width = 0.12, size = 2.8, alpha = 0.7, color = "black") +
  geom_hline(yintercept = 1, linetype = "dashed", color = "red", linewidth = 0.8) +
  scale_fill_brewer(palette = "Set1") +
  theme_pubr() +
  labs(
    title = "Relative mRNA Expression of p53 Target Gene",
    subtitle = "Normalized to GAPDH & ACTB Geometric Mean (2^-ΔΔCq Method)",
```
