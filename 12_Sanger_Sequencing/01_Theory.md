# ۱۲ — توالی‌یابی سنگر: شیمی ختم زنجیره، الکتروفورز مویینه و خوانش کروماتوگرام

> **هدف:** فهم اینکه چطور توالی یک قطعه‌ی DNA با ddNTPهای فلورسنت و الکتروفورز مویینه خوانده می‌شود، چه چیزی کیفیت توالی را تعیین می‌کند و چگونه یک کروماتوگرام را روی بنچ ارزیابی کنیم.
>
> **پیش‌نیاز:** فصل‌های ۰۵ (PCR) و ۰۹ (الکتروفورز).
>
> **فصل‌های مرتبط:** ۱۳ (NGS)، ۱۴ (تأیید کلون)، ۱۶ (شناسایی با 16S)، ۱۷ (MLST).
>
> **محدوده:** هم‌ردیف‌سازی و آنالیز بیوانفورماتیک خارج از این مخزن است؛ این‌جا فقط **کنترل کیفیت کروماتوگرام** آمده است.

---

## ۱. اصل ختم زنجیره (سنگر، ۱۹۷۷)
- پلیمراز برای افزودن نوکلئوتید بعدی به گروه **3'-OH** نیاز دارد (فصل ۰۵، بخش ۲.۳).
- **دی‌دئوکسی‌نوکلئوتید (ddNTP)** در کربن ۳' به‌جای OH، **هیدروژن** دارد ← پس از ورود به زنجیره، **هیچ نوکلئوتید دیگری اضافه نمی‌شود** ← ختم زنجیره.
- واکنش شامل **dNTP فراوان + مقدار کمی ddNTP** است ← در هر موقعیت، احتمال کمی هست که ddNTP به‌جای dNTP وارد شود ← مخلوطی از قطعات با **همه‌ی طول‌های ممکن** که هر کدام با ddNTP متناظر با آخرین باز خود ختم شده‌اند.
- جداسازی این قطعات بر اساس **طول با تفکیک یک نوکلئوتید** و شناسایی ddNTP انتهایی ← توالی.

---

## ۲. شیمی امروزی: Dye-terminator و Cycle sequencing

### ۲.۱. ddNTPهای فلورسنت (BigDye Terminator)
- هر یک از **چهار ddNTP** با **فلوروفور متفاوت** نشان‌دار شده است ← هر چهار واکنش در **یک لوله** و یک مویینه.
- **رنگ‌های انتقال انرژی (Energy-transfer dyes):** هر برچسب یک **دهنده** (مشتق فلورسئین) دارد که با **یک طول موج لیزر** برانگیخته می‌شود و انرژی را با FRET به **گیرنده** (مشتق دی‌کلرورودامین) منتقل می‌کند؛ گیرنده‌ها چهار رنگ نشر متفاوت دارند ← **یک لیزر، چهار رنگ متمایز، شدت زیاد**.
- **پلیمراز مهندسی‌شده:** Taq طبیعی ddNTPها را **بسیار ضعیف‌تر** از dNTP وارد می‌کند (تمایز قند). جهش **F667Y** (فنیل‌آلانین به تیروزین) این تمایز را تقریباً حذف می‌کند ← ورود یکنواخت ddNTP ← ارتفاع قله‌های یکنواخت‌تر. همچنین فعالیت اگزونوکلئازی 5'→3' حذف یا کاهش یافته است.

### ۲.۲. Cycle sequencing (توالی‌یابی چرخه‌ای)
- **فقط یک پرایمر** ← تکثیر **خطی** (نه نمایی): در هر سیکل، الگوی اصلی دوباره کپی و ختم می‌شود.
- برنامه‌ی دمایی: واسرشت ۹۶°C، اتصال ۵۰°C، گسترش **۶۰°C** (دمای پایین‌تر از ۷۲°C برای ورود بهتر ddNTPها و ختم)؛ ۲۵ سیکل.
- **چرا ۲۵ سیکل؟** محصول خطی به حدود ۲۵ برابر می‌رسد؛ مقدار کافی برای آشکارسازی بدون مصرف کامل ddNTPها.

### ۲.۳. نسبت ddNTP:dNTP و طول خوانش
نسبت بیشتر ← ختم‌های زودتر ← قطعات کوتاه‌تر و سیگنال قوی در ابتدا؛ نسبت کمتر ← قطعات بلندتر. فرمول‌های تجاری برای **طول خوانش حدود ۷۰۰ تا ۱۰۰۰ باز** بهینه شده‌اند.

## ۳. الکتروفورز مویینه (Capillary Electrophoresis) — مهندسی دستگاه

### ۳.۱. اجزا (مثلاً Applied Biosystems 3500 / 3730xl)
| جزء | توضیح |
| :--- | :--- |
| **آرایه‌ی مویینه** | ۸، ۲۴، ۴۸ یا ۹۶ مویینه‌ی **سیلیکای ذوب‌شده** با قطر داخلی حدود **۵۰ میکرون** و طول مؤثر **۳۶ یا ۵۰ سانتی‌متر**؛ پوشش پلی‌ایمید بیرونی برای انعطاف (در **پنجره‌ی آشکارسازی** برداشته شده) |
| **پلیمر جداکننده** (مثلاً **POP-7**) | پلی‌دی‌متیل‌آکریل‌آمید خطی (غیرشبکه‌ای) در **اوره** (واسرشت‌کننده)؛ هم ماتریس غربالی و هم **پوشش دینامیک دیواره** که **جریان الکترواسمزی** را سرکوب می‌کند |
| **پمپ پلیمر** | پر کردن مویینه‌ها با پلیمر تازه پیش از **هر ران** |
| **آون** | دمای ثابت حدود **۶۰°C** — واسرشت و مهاجرت تکرارپذیر |
| **منبع ولتاژ بالا** | تزریق حدود ۱ تا ۲ kV؛ ران حدود **۸ تا ۱۵ kV** |
| **لیزر** | حالت جامد **۵۰۵ نانومتر** (3500) یا آرگون **۴۸۸/۵۱۴.۵ نانومتر** (3730 قدیمی) |
| **آشکارساز** | نور نشر از پنجره‌ی همه‌ی مویینه‌ها ← **طیف‌نگار (Spectrograph)** با توری پراش ← **دوربین CCD** که کل طیف را هم‌زمان ثبت می‌کند |

### ۳.۲. تزریق الکتروکینتیک — چرا تمیز کردن واکنش حیاتی است؟
نمونه با **ولتاژ** وارد مویینه می‌شود (نه فشار). مقدار ورودی هر یون با **تحرک و غلظت** آن متناسب است. **یون‌های کوچک** (کلرید، استات، و به‌ویژه **ddNTPهای رنگی آزاد** و نمک‌ها) بسیار پرتحرک‌اند و **با DNA رقابت** می‌کنند ← DNA کمتری وارد می‌شود ← سیگنال ضعیف. به همین دلیل:
- واکنش توالی‌یابی باید **تمیز** شود (رسوب اتانول/EDTA یا معرف‌هایی مثل BigDye XTerminator یا ستون‌های ژل فیلتراسیون).
- نمونه در **فرمامید Hi-Di** (فرمامید بسیار خالص با رسانایی کم) حل می‌شود.

### ۳.۳. کالیبراسیون طیفی (Spectral calibration)
طیف نشر چهار رنگ **همپوشانی** دارد. دستگاه با یک استاندارد ماتریس، **ماتریس جبران** را می‌سازد تا سیگنال هر کانال از نشت رنگ‌های دیگر پاک شود. باید برای **هر مجموعه رنگ (Dye set)** و هر آرایه انجام شود. ماتریس نادرست ← قله‌های **«Pull-up»** (قله‌ی کوچک کاذب زیر قله‌ی قوی در رنگ دیگر).

### ۳.۴. تصحیح تحرک (Mobility correction)
رنگ‌های مختلف تحرک قطعات را **کمی متفاوت** تغییر می‌دهند. نرم‌افزار با **فایل تحرک** مخصوص شیمی و پلیمر، فاصله‌ی قله‌ها را تصحیح می‌کند. فایل اشتباه ← فاصله‌ی ناهمگون قله‌ها و Base calling ضعیف.

## ۴. کروماتوگرام و کیفیت

### ۴.۱. نمره‌ی کیفیت Phred (QV)
$$QV = -10\log_{10}(P_{\text{error}})$$
| QV | احتمال خطا | دقت |
| :--- | :--- | :--- |
| 10 | 1/10 | 90% |
| **20** | **1/100** | **99%** — حد معمول «قابل اعتماد» |
| 30 | 1/1000 | 99.9% |
| 40 | 1/10000 | 99.99% |
- **QV20+** (Quality Read Length): تعداد بازهای با QV ≥ ۲۰. یک ران خوب معمولاً **۷۰۰ تا ۹۰۰** باز QV20+ دارد.

### ۴.۲. ساختار طبیعی یک کروماتوگرام خوب
| ناحیه | ویژگی |
| :--- | :--- |
| **۲۰ تا ۴۰ باز اول** | کیفیت **پایین** (نزدیک پرایمر؛ قطعات کوتاه سریع و تفکیک ضعیف) ← **پرایمر توالی‌یابی را حداقل ۵۰ باز بالادست** ناحیه‌ی مورد علاقه طراحی کنید |
| **حدود ۴۰ تا ۷۰۰ باز** | قله‌های **تیز، هم‌فاصله، منفرد**، زمینه‌ی پایین |
| **پس از حدود ۷۰۰ تا ۹۰۰** | پهن شدن قله‌ها، کاهش تفکیک ← QV پایین |
| **حدود ۷۰ تا ۸۰ باز** (گاهی) | **«Dye blob»**: قله‌ی پهن و بزرگ از ddNTPهای رنگی آزاد که حذف نشده‌اند (تمیز کردن ناقص) |

### ۴.۳. الگوهای مهم
| الگو | معنی |
| :--- | :--- |
| **دو قله‌ی هم‌مکان در یک موقعیت** (سراسر توالی سالم) | **هتروزیگوت** (SNP در یوکاریوت دیپلوئید) یا **دو نسخه‌ی متفاوت** ژن در باکتری (اپرون‌های 16S، ژن‌های پارالوگ) |
| **توالی تمیز ← از یک نقطه به بعد قله‌های دوگانه همه‌جا** | **درج یا حذف (Indel)** در یکی از دو الگو (هتروزیگوت) یا **مخلوط دو الگو** با طول متفاوت |
| **قله‌های دوگانه در سراسر توالی از ابتدا** | **الگوی مخلوط** (دو محصول PCR، دو کلنی، دو پلاسمید)؛ یا **دو پرایمر** (پرایمر PCR باقیمانده) |
| **کاهش ناگهانی سیگنال** پس از یک ناحیه | **ساختار دوم** (سنجاق‌سر) یا ناحیه‌ی پر GC؛ **تکرار هموپلیمر** طولانی (لغزش پلیمراز) |
| **سیگنال پایین و نویزی** در کل | الگو یا پرایمر کم؛ نمک زیاد؛ مهار |
| **سیگنال بسیار قوی ابتدا و افت سریع** («Top-heavy») | **الگوی زیاد** ← ddNTPها زود مصرف می‌شوند |

## ۵. پیروسکوئنسینگ (Pyrosequencing) — مرور کوتاه
- **توالی‌یابی با سنتز** و **آشکارسازی پیروفسفات** آزادشده: در هر بار، **یک نوع dNTP** اضافه می‌شود؛ اگر وارد شود، PPi آزاد ← **ATP سولفوریلاز** آن را به **ATP** تبدیل می‌کند ← **لوسیفراز** با ATP نور تولید می‌کند ← نور متناسب با **تعداد** نوکلئوتیدهای وارد شده. **آپیراز** dNTPهای مصرف‌نشده را تخریب می‌کند. (به‌جای dATP از **dATPαS** استفاده می‌شود که لوسیفراز آن را سوبسترا نمی‌شناسد.)
- **کاربرد:** خوانش‌های **کوتاه** (۵۰ تا ۱۰۰ باز) با **کمی‌سازی دقیق آلل‌ها** (درصد جهش، متیلاسیون CpG پس از بی‌سولفیت). اساس پلتفرم قدیمی 454 (فصل ۱۳).

## ۶. سنگر در عصر NGS — چه زمانی؟
| کاربرد | چرا سنگر؟ |
| :--- | :--- |
| **تأیید کلون و جهش‌زایی** (فصل ۱۴) | چند صد باز، دقت بسیار بالا، ارزان |
| **MLST** (فصل ۱۷) | ۷ قطعه‌ی ۴۰۰ تا ۵۰۰ bp |
| **شناسایی با 16S rRNA** (فصل ۱۶) | حدود ۱۵۰۰ bp با دو یا چند پرایمر |
| **تأیید یافته‌های NGS** | «استاندارد طلایی» برای واریانت‌های تک |
| **محدودیت** | واریانت‌های با فراوانی کمتر از حدود **۱۵ تا ۲۰٪** در مخلوط دیده نمی‌شوند (NGS برای حساسیت بالاتر) |
