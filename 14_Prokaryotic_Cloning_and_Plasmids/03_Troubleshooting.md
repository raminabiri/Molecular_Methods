# ۱۴ — عیب‌یابی تخصصی کلونینگ و پلاسمید

> **اصل کارشناسی:** کلونینگ ناموفق را با **کنترل‌ها** تشخیص بدهید، نه با حدس. سه کنترل لیگاسیون (وکتور+لیگاز، وکتور بدون لیگاز، پلاسمید حلقوی) و یک **PCR کلنی** تقریباً همیشه محل مشکل را مشخص می‌کنند.

---

## ۰. درخت تصمیم
```
کنترل پلاسمید حلقوی کلنی داد؟ ── نه ──> سلول‌های مستعد یا پلیت/آنتی‌بیوتیک (بخش ۱)
      │ بله
وکتور بدون لیگاز کلنی زیاد داد؟ ── بله ──> هضم ناقص وکتور (بخش ۲.۱)
      │ نه
وکتور + لیگاز (بدون Insert) کلنی زیاد داد؟ ── بله ──> خودبستگی: دفسفریلاسیون یا هضم تک‌آنزیمی (بخش ۲.۲)
      │ نه
لیگاسیون کامل کلنی نداد؟ ──> Insert، لیگاز، یا نسبت (بخش ۳)
کلنی هست اما همه بدون Insert؟ ──> بخش ۴
```

---

## ۱. هیچ کلنی‌ای رشد نکرد (حتی کنترل پلاسمید حلقوی)
| علت | آزمون | اقدام |
| :--- | :--- | :--- |
| **سلول‌های مستعد مرده** (ذوب در دست، انجماد دوباره، فریزر Frost-free، کهنه) | کارایی را با ۱۰ pg و ۱ ng pUC19 بسنجید | الیکوت نو؛ ذوب روی یخ؛ هرگز انجماد دوباره |
| **آنتی‌بیوتیک اشتباه یا غلظت زیاد** | پلیت را با سلول بدون پلاسمید و پلاسمید معلوم آزمون کنید | بازبینی نشانگر پلاسمید (نقشه!) و غلظت |
| **آنتی‌بیوتیک در آگار داغ تخریب شده** یا پلیت کهنه | پلیت تازه | افزودن در ۵۰ تا ۵۵°C؛ پلیت‌ها حداکثر چند هفته در ۴°C |
| **شوک حرارتی بیش از حد** (زمان یا دما) | — | تایمر؛ ۴۲°C، ۳۰ تا ۴۵ ثانیه |
| **بازیابی بدون SOC یا بسیار کوتاه** | — | SOC و ۶۰ دقیقه (برای Kan/Cm اجباری) |
| **DNA زیاد یا حجم DNA زیاد** (نمک، گلیسرول، EDTA) | — | حداکثر ۵٪ حجم؛ لیگاسیون دسالت‌شده |
| **قوس در الکتروپوریشن** | ثابت زمانی بسیار کم | دسالت DNA؛ کووت سرد و خشک |

---

## ۲. زمینه‌ی بالا (کلنی زیاد در کنترل‌ها)

### ۲.۱. وکتور **بدون لیگاز** کلنی می‌دهد
**یعنی وکتور حلقوی هضم‌نشده باقی مانده است.**
| علت | اقدام |
| :--- | :--- |
| هضم ناقص (آنزیم کم، زمان کم، بافر اشتباه، گلیسرول زیاد) | آنزیم و زمان بیشتر؛ **ژل کنترل: باند ابرپیچ باید کامل ناپدید شود** |
| **متیلاسیون Dam/Dcm** جایگاه را مسدود کرده | پلاسمید از سویه‌ی *dam*⁻ *dcm*⁻؛ آنزیم جایگزین |
| آنزیم غیرفعال (ذوب و انجماد، کهنه) | Lot نو |
| وکتور خالص‌نشده (هضم‌نشده همراه) | **برش از ژل** وکتور خطی — مؤثرترین راه |

### ۲.۲. وکتور **+ لیگاز** (بدون Insert) کلنی زیاد می‌دهد
| علت | اقدام |
| :--- | :--- |
| **خودبستگی** (هضم با یک آنزیم یا دو آنزیم با انتهای سازگار) | **دفسفریلاسیون با rSAP**؛ یا دو آنزیم با انتهای ناسازگار (کلونینگ جهت‌دار) |
| دفسفریلاسیون ناقص | rSAP تازه، ۳۰ دقیقه، سپس غیرفعال‌سازی |
| قطعه‌ی کوچک بین دو جایگاه، دوباره متصل شده | برش از ژل |

---

## ۳. کلنی در لیگاسیون کامل نیست (اما کنترل‌ها درست)
| علت | شاهد | اقدام |
| :--- | :--- | :--- |
| **Insert هضم نشده** (برش نزدیک انتهای PCR) | — | **۴ تا ۶ باز محافظ** در پرایمرها؛ هضم طولانی‌تر؛ خالص‌سازی محصول PCR پیش از هضم |
| **بافر لیگاز خراب** (ATP تجزیه‌شده) | کنترل مثبت لیگاسیون (قطعه و وکتور معلوم) | **الیکوت بافر**؛ Lot نو |
| **نسبت مولی نامناسب** | — | ۱:۱، ۳:۱ و ۷:۱ را موازی آزمون کنید |
| **Insert بسیار بزرگ** (بیش از چند kb) | — | زمان لیگاسیون بیشتر (۱۶°C یک شب)؛ غلظت DNA کمتر؛ وکتور کم‌نسخه |
| **کمی‌سازی اشتباه** قطعه‌ی برش‌خورده | Qubit یا تخمین از ژل | — |
| **اتانول یا نمک باقیمانده** از خالص‌سازی | — | سانتریفیوژ خشک؛ الوشن در آب یا EB |
| **سمیت Insert برای *E. coli*** | کلنی‌های بسیار ریز یا رشد کند | وکتور کم‌نسخه؛ پروموتر القایی سخت‌گیرانه؛ سویه‌ی مناسب؛ ۳۰°C |

---

## ۴. کلنی زیاد اما بدون Insert درست
| مشاهده | تفسیر | اقدام |
| :--- | :--- | :--- |
| PCR کلنی: همه باند **وکتور خالی** | زمینه‌ی خودبستگی (بخش ۲) | — |
| PCR کلنی: باند با **اندازه‌ی غیرمنتظره** | **حذف درون Insert** (توالی‌های تکراری یا سمی)، چند Insert پشت سر هم، یا بازآرایی | سویه‌ی *recA*⁻؛ توالی‌یابی؛ وکتور کم‌نسخه |
| توالی: **جهش نقطه‌ای** در Insert | خطای PCR | پلیمراز **Proofreading**؛ سیکل کمتر؛ چند کلون را توالی‌یابی کنید |
| **کلنی سفید بدون Insert** (آبی-سفید) | جهش یا حذف در *lacZα*؛ یا کلنی‌های سفید کاذب | همیشه با PCR کلنی تأیید کنید |
| **کلنی آبی با Insert** | Insert کوچک و «در قالب» که فعالیت α را حفظ کرده | به رنگ اعتماد نکنید |
| **کلنی‌های اقماری ریز دور کلنی‌های بزرگ** | β-لاکتاماز ترشح‌شده آمپی‌سیلین محیط را تجزیه کرده | **کاربنی‌سیلین**؛ انکوباسیون حداکثر ۱۶ ساعت؛ پلیت تازه؛ فقط کلنی‌های بزرگ و جدا را بردارید |

## ۵. مینی‌پرپ
| مشکل | علت ریشه‌ای | اقدام |
| :--- | :--- | :--- |
| **بازده کم** | کشت زیاد (ستون اشباع)؛ پلاسمید کم‌نسخه؛ رسوب در P1 کامل حل نشده؛ پلاسمید بزرگ | کشت کمتر یا کیت Midi؛ برای پلاسمید کم‌نسخه حجم بیشتر و کیت مناسب؛ الوشن با بافر گرم (۵۰°C) |
| **آلودگی DNA ژنومی** (باند بزرگ یا اسمیر) | ورتکس پس از P2؛ زمان قلیایی طولانی؛ مرحله‌ی خنثی‌سازی کند | سروته کردن آرام؛ **حداکثر ۵ دقیقه**؛ افزودن سریع N3 |
| **آلودگی RNA** (ابر در پایین ژل) | RNase در P1 فعال نیست (بافر کهنه یا دمای نگهداری) | P1 نو (RNase پس از افزودن در ۴°C نگهداری شود) |
| **پلاسمید دناتوره‌ی برگشت‌ناپذیر** (باند تیز سریع‌تر؛ هضم و توالی‌یابی ناموفق) | **زمان قلیایی طولانی** یا NaOH غلیظ | زمان‌بندی دقیق؛ دوباره مینی‌پرپ |
| **260/230 پایین** | گوانیدین | شستشوی PB و PE؛ رسوب دوباره |
| **پلاسمید «گم‌شده»** پس از چند پاساژ | ناپایداری، سمیت Insert، آنتی‌بیوتیک ناکافی | همیشه از **استوک گلیسرولی** شروع کنید، نه از پلیت کهنه؛ آنتی‌بیوتیک در همه‌ی مراحل |
| **اندازه‌ی غیرمنتظره در ژل** | فرم ابرپیچ در برابر خطی (فصل ۰۹، بخش ۴) | برای اندازه، **خطی کنید** |

## ۶. بیان پروتئین
(جزئیات حلالیت و خالص‌سازی در فصل ۰۴، عیب‌یابی)
| مشکل | علت | اقدام |
| :--- | :--- | :--- |
| **بدون بیان** | پلاسمید در سویه‌ی غیر-(DE3)؛ قالب خوانش (Frame) اشتباه؛ کدون پایان؛ IPTG کهنه؛ پلاسمید از دست رفته | توالی‌یابی محل اتصال و قالب؛ سویه‌ی درست؛ IPTG نو؛ کلنی تازه از استوک |
| **بیان پایه قبل از القا** | پروموتر T7 نشتی | pLysS؛ گلوکز ۱٪؛ سیستم araBAD |
| **رشد پس از القا متوقف می‌شود** | سمیت پروتئین | ۱۸ تا ۲۵°C؛ IPTG کمتر؛ القا در OD بالاتر |
| **پروتئین کوتاه‌تر از انتظار** | پروتئولیز؛ شروع داخلی؛ کدون نادر | BL21؛ Rosetta؛ مهارکننده‌ها |

## ۷. پلاسمیدهای طبیعی و مقاومت (نگاه بالینی)
| موقعیت | تفسیر و اقدام |
| :--- | :--- |
| **کونژوگاسیون ناموفق** | پلاسمید **غیرخودانتقال** (فقط Mobilizable یا بدون *oriT*)؛ سازگاری گیرنده؛ شرایط هم‌کشتی. آزمون: روش فیلتر روی پلیت، نسبت‌های مختلف، زمان طولانی‌تر، گیرنده‌ی دیگر؛ در نهایت **الکتروپوریشن پلاسمید** به گیرنده برای اثبات انتقال‌پذیری ژن |
| **رشد روی پلیت انتخابی در کنترل‌ها** | **جهش خودبه‌خود مقاومت** گیرنده یا اهداکننده ← کنترل‌ها اجباری‌اند؛ انتخاب‌گر دیگر یا غلظت بالاتر |
| **ترانس‌کونژوگانت مشکوک** | ممکن است اهداکننده‌ی مقاوم به آزید جهش‌یافته باشد ← **تأیید هویت** (بیوشیمیایی، PCR اختصاصی، یا MALDI-TOF؛ فصل ۱۶) |
| **Curing ناموفق** | پلاسمید پایدار (سیستم‌های Addiction مانند پس-تفکیکی کشنده) یا ژن **کروموزومی** است ← S1-PFGE + سادرن (فصل ۱۰) یا WGS (فصل ۱۳) برای تعیین محل |
| **فنوتیپ مقاومت پس از Curing باقی می‌ماند** | ژن کروموزومی، یا نسخه‌ی دوم ژن، یا سازوکار دیگر (پمپ خروجی، تغییر نفوذپذیری) | WGS |
