# ۱۴ — جداول مرجع کلونینگ و پلاسمید

---

## جدول ۱ — فرمول‌ها
| کمیت | فرمول |
| :--- | :--- |
| جرم Insert برای نسبت مولی | $\text{ng}_{\text{ins}} = \text{ng}_{\text{vec}} \times (L_{\text{ins}}/L_{\text{vec}}) \times \text{ratio}$ |
| کارایی ترانسفورماسیون | $\text{cfu}/\mu\text{g} = \text{colonies} / \mu\text{g DNA}$ |
| تعداد مولکول پلاسمید | $N = m_{(\text{g})} \times 6.022\times10^{23} / (L_{\text{bp}} \times 650)$ |
| فراوانی کونژوگاسیون | cfu ترانس‌کونژوگانت ÷ cfu اهداکننده (روش را ذکر کنید) |
