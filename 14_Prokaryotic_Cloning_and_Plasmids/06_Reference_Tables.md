## جدول ۱ — فرمول‌ها
| کمیت | فرمول |
| :--- | :--- |
| جرم Insert برای نسبت مولی | $\text{ng}_{\text{ins}} = \text{ng}_{\text{vec}} \times (L_{\text{ins}}/L_{\text{vec}}) \times \text{ratio}$ |
| کارایی ترانسفورماسیون | $\text{cfu}/\mu\text{g} = \text{colonies} / \mu\text{g DNA}$ |
| تعداد مولکول پلاسمید | $N = m_{(\text{g})} \times 6.022\times10^{23} / (L_{\text{bp}} \times 650)$ |
| فراوانی کونژوگاسیون | cfu ترانس‌کونژوگانت ÷ cfu اهداکننده (روش را ذکر کنید) |

## جدول ۱۳ — کنترل‌های اختصاصی هر روش کلونینگ
| روش | کنترل اجباری | اگر کنترل کلنی داد |
| :--- | :--- | :--- |
| لیگاسیون | وکتور + لیگاز **بدون قطعه** | هضم ناقص یا دفسفریلاسیون ناموفق |
| TA | وکتور T + لیگاز بدون قطعه | وکتور خودبسته؛ Lot را بررسی کنید |
| Gibson | **وکتور خطی + مسترمیکس بدون قطعه** | **وکتور حلقوی باقی‌مانده** ← هضم/PCR + DpnI + ژل |
| Golden Gate | وکتور مقصد + آنزیم + لیگاز بدون قطعه | جایگاه داخلی یا هضم ناقص |
| Gateway | واکنش LR بدون کلون ورودی | آلودگی با وکتور؛ **ccdB** باید همه را بکشد |
| جهش‌زایی | واکنش **بدون پرایمر** (فقط الگو) | **DpnI کافی عمل نکرده** ← الگوی متیله باقی مانده |
