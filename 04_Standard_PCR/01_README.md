# Comprehensive PCR Documentation Suite: From Fundamentals to Multiplex Optimization

این مخزن (Repository) یک مجموعه مستندات جامع، پداگوژیک، گام‌به‌گام و استاندارد برای آموزش صفر تا صد تکنیک‌های واکنش زنجیره‌ای پلیمراز (PCR)، از اصول پایه‌ای تا طراحی مالتی‌پلکس، محاسبات پیشرفته، برنامه‌ریزی دستگاه‌های Bio-Rad و عیب‌یابی آزمایشگاهی است.

---

## 📂 ساختار ماژولار مستندات (Repository Architecture)

تمامی ماژول‌ها در ساختاری استاندارد جهت استفاده در گیت‌هاب و مستندسازی آزمایشگاهی تدوین شده‌اند:

1. **`01-PCR_History_and_Principles.md`**
   * تاریخچه جامع (با ذکر نقش کلیدی کری مولیس)، اصول مکانیکی، ترمودینامیکی و بررسی تخصصی انواع PCR (شامل Rapid، RAPD، ERIC، AFLP و Gap-PCR).
2. **`02-PCR_Buffers_and_Reagents.md`**
   * بررسی ساختار شیمیایی بافرها، نقش یون منیزیم، dNTPs، عوامل افزودنی (DMSO, Betaine) و شرایط انبارش استاندارد.
3. **`03-PCR_Kits_and_Commercial_Systems.md`**
   * دسته‌بندی کیت‌های تجاری استخراج و تکثیر، آنزیم‌های Hot-Start و مقایسه سیستم‌های مختلف.
4. **`04-Masermix_PCRmixs_Calculations.md`**
   * اصول ریاضی ساخت مسترمیکس، ضریب خطای $N+1$، فرمول‌های کامل رقیق‌سازی پرایمرها، تبدیل واحدها و مسائل تمرینی کاربردی.
5. **`05-Biorad_Programming.md`**
   * اصول مهندسی ترموسایکلرها، تکنولوژی پلتیر، راهنمای جامع دستگاه‌های Bio-Rad (C1000 / T100)، برنامه‌ریزی گرادیان و دستورالعمل نگهداری پیشگیرانه (Preventive Maintenance).
6. **`06-Multiplex_PCR_Calculations.md`**
   * راهنمای گام‌به‌گام طراحی و بهینه‌سازی Multiplex PCR، مدیریت تداخلات پرایمری (Heterodimers) و تنظیم غلظت‌ها.
7. **`07-Troubleshooting_Flowchart_and_Lab_Log.md`**
   * جریان‌نمای تصمیم‌گیری سریع عیب‌یابی (Troubleshooting Flowchart) و فرم استاندارد ثبت لاگ آزمایشگاهی (Lab Log Sheet).
8. **`08-Standard_Reference_Tables.md`**
   * جداول جامع مرجع برای بازسازی پرایمرها، فرمولاسیون مسترمیکس، مقایسه برندها و رفع خطاهای رایج.

## 🎯 اهداف پداگوژیک و ویژگی‌ها
* **محاسباتی و تحلیلی:** ارائه مسائل کاربردی با پاسخ‌نامه تشریحی کامل.
* **استاندارد آزمایشگاهی:** تاکید بر اصول ایمنی، کنترل‌های مثبت و منفی (NTC)، و نگهداری زنجیره سرما (Cold Chain).
* **مناسب برای پژوهشگران و دانشجویان:** ساختاریافته برای استفاده در آزمایشگاه‌های ژنتیک پزشکی، میکروب‌شناسی و بیوتکنولوژی.
