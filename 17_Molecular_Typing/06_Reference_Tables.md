# ۱۷ — جداول مرجع تایپینگ مولکولی

> ⚠️ عددهای **🔎** را با **دستورالعمل رسمی همان شبکه/طرح** (PulseNet، PubMLST، Supply ۲۰۰۶، Kamerbeek ۱۹۹۷) و دفترچه‌ی کیت تأیید کنید. آنزیم، پارامتر ران و مجموعه‌ی لوکوس **گونه‌به‌گونه متفاوت** است.

---

## جدول ۱ — فرمول‌ها
| کمیت | فرمول |
| :--- | :--- |
| **شاخص تنوع سیمپسون** | $D = 1 - \dfrac{1}{N(N-1)}\sum n_j(n_j-1)$ |
| **ضریب Dice** (شباهت الگوی باند) | $S_D = \dfrac{2n_{AB}}{n_A + n_B}$ |
| ضریب Jaccard | $S_J = \dfrac{n_{AB}}{n_A + n_B - n_{AB}}$ |
| **تعداد تکرار در VNTR** | $n = \dfrac{L_{\text{محصول}} - L_{\text{فلانکینگ}}}{L_{\text{یک تکرار}}}$ |
| تعداد قطعه‌ی مورد انتظار (توالی تصادفی) | $N_{\text{قطعه}} \approx \dfrac{L_{\text{ژنوم}}}{4^{k}}$ ($k$ = طول جایگاه) |
| نمایه‌های آللی ممکن در MLST | $\prod_{i=1}^{7} a_i$ ($a_i$ = تعداد آلل لوکوس $i$) |
| ارزش رقم اکتال اسپولیگو | $4b_1 + 2b_2 + 1b_3$ |
> 🔎 $D \ge 0{,}95$ به‌طور سنتی برای کاربرد اپیدمیولوژیک مطلوب است.

## جدول ۲ — مقایسه‌ی روش‌ها
| روش | 🔎 تفکیک | قابلیت انتقال | 🔎 زمان | تجهیزات | خروجی | کاربرد اصلی |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **ERIC/rep-PCR** | متوسط | **ضعیف** | **۱ روز** | PCR + ژل | الگوی باند | **غربالگری درون‌آزمایشگاهی** |
| **PFGE** | **بالا** | ضعیف/متوسط | **۳–۵ روز** | سیستم **CHEF** | الگوی باند | طغیان (استاندارد تاریخی) |
| **MLST** | متوسط | **عالی** | ۲–۳ روز | ۷ لوکوس سنگر | **ST** | **ساختار جمعیتی جهانی** |
| **MLVA/MIRU-VNTR** | **بالا** | **خوب** | ۱–۲ روز | PCR چندگانه + مویرگی | **کد عددی** | طغیان؛ MTB |
| **اسپولیگوتایپینگ** | **کم** | **عالی** | ۱–۲ روز | هیبریداسیون/Luminex | **کد اکتال** | **خط تکاملی MTB** |
| **WGS (cgMLST/SNP)** | **بالاترین** | **عالی** | روز–هفته | توالی‌یاب + زیرساخت محاسباتی | آلل/SNP | **مرجع امروزی** |

## جدول ۳ — 🔎 آنزیم‌های PFGE بر اساس گونه
| گونه | آنزیم رایج |
| :--- | :--- |
| *Salmonella*، *E. coli* O157، *Shigella* | **XbaI** |
| *Klebsiella*، *Enterobacter* | **XbaI** |
| *S. aureus*، *Enterococcus* | **SmaI** (🔎 ۲۵°C) |
| *Listeria monocytogenes* | **AscI** (و ApaI) |
| *Campylobacter* | **SmaI** (و KpnI) |
| *Acinetobacter baumannii* | **ApaI** |
| *Pseudomonas aeruginosa* | **SpeI** |
> ❗ آنزیم PFGE نه فقط به دلیل **طول جایگاه**، بلکه به دلیل **کم‌نماینده بودن جایگاه در ژنوم آن گونه** انتخاب می‌شود؛ به همین دلیل یک آنزیم برای همه مناسب نیست. آنزیم، واحد و دما را از **پروتکل رسمی همان گونه** بگیرید.
> **نشانگر اندازه‌ی جهانی:** *Salmonella* ser. **Braenderup H9812** هضم‌شده با **XbaI** — 🔎 در چاهک‌های ۱، ۵، ۱۰، ۱۵.

## جدول ۴ — 🔎 بافرها و پارامترهای PFGE

| :--- | :--- |
| **CSB** (سوسپانسیون) | ۱۰۰ mM Tris + ۱۰۰ mM EDTA، pH ۸٫۰ |
| **CLB** (لیز) | ۵۰ mM Tris + ۵۰ mM EDTA، pH ۸٫۰ + ۱٪ سارکوزین |
| **TE** | ۱۰ mM Tris + ۱ mM EDTA، pH ۸٫۰ |
| بافر ران | **۰٫۵× TBE** (تازه) |
| پروتئیناز K | استوک ۲۰ mg/mL |
| آگارز | **ویژه‌ی PFGE (کم-EEO)**، ۱٪ |
| لیز | ۵۴–۵۵°C، ۱٫۵–۲ ساعت، تکان ۱۵۰–۱۷۵ rpm |
| شست‌وشو | **۲× آب + ۴× TE**، هر بار ۱۰–۱۵ دقیقه در ۵۴°C |

> ❗ **رمپ زمان پالس** پنجره‌ی اندازه‌ای تفکیک را تعیین می‌کند و برای هر گونه/آنزیم متفاوت است.

## جدول ۶ — 🔎 ERIC/rep-PCR
| مورد | مقدار |
| :--- | :--- |
| **ERIC1R** | `ATGTAAGCTCCTGGGGATTCAC` |
| **ERIC2** | `AAGTAAGTGACTGGGGTGAGCG` |
| عنصر ERIC | ~۱۲۶ bp، بین‌ژنی |
| عنصر REP | ~۳۵ bp (پرایمرهای REP1R-I/REP2-I) |
| DNA در واکنش | **۲۰–۵۰ ng، یکسان برای همه‌ی نمونه‌ها** |
| دمای اتصال | ~۵۲°C |
| بسط | ۷۲°C، ۲–۳ دقیقه |
| چرخه | ۳۰–۳۵ |
| ژل | آگارز **۱٫۵٪** در ۰٫۵× TBE، ولتاژ پایین، ران طولانی |
| نشانگر | **هر ۵ چاهک** تکرار شود |
> ⚠️ همه‌ی نمونه‌های یک مطالعه: **یک ران، یک Lot، یک دستگاه**. داده‌ی دو ران را ترکیب نکنید.

## جدول ۷ — MLST
| مورد | توضیح |
| :--- | :--- |
| تعداد لوکوس | **۷** ژن خانه‌دار (🔎 قطعات ~۴۰۰–۶۰۰ bp) |
| پلیمراز | **High-Fidelity** (خطای پلیمراز = آلل کاذب) |
| توالی‌یابی | **دوطرفه، اجباری** |
| تعریف آلل | **هر تفاوت تک‌نوکلئوتیدی = آلل جدید** (تعداد تفاوت‌ها ثبت نمی‌شود) |
| خروجی | نمایه‌ی آللی ← **ST** |
| گروه‌بندی | **eBURST/goeBURST** ← کمپلکس کلونال؛ **SLV** = اختلاف در ۱ لوکوس |
| پایگاه داده | **PubMLST/BIGSdb** (طرح‌ها، پرایمرها، تخصیص آلل و ST) |
| محدودیت | **تفکیک ناکافی برای طغیان** ← MLVA/PFGE/cgMLST |

## جدول ۸ — MLVA و MIRU-VNTR (MTB)
| مورد | توضیح |
| :--- | :--- |
| آلل | **تعداد نسخه‌های تکرار** (عدد صحیح) |
| مجموعه‌ی استاندارد MTB | 🔎 **۲۴ لوکوس** (Supply و همکاران، ۲۰۰۶)؛ زیرمجموعه‌ی **۱۵ لوکوس** برای غربالگری |
| پرایمرها و **جدول تخصیص آلل** | ❗ **فقط از مرجع رسمی** (Supply ۲۰۰۶ / MIRU-VNTR*plus*) — از حافظه یا منابع غیررسمی استفاده نکنید |
| تعیین اندازه | **الکتروفورز مویرگی** با نشانگر داخلی (ژل معمولاً برای تفاوت یک تکرار کافی نیست) |
| کنترل | **سویه‌ی مرجع با کد منتشرشده** (مثل H37Rv) در هر ران |
| پایگاه داده | **MIRU-VNTR*plus*** (خط تکاملی و خوشه‌بندی) |
| مشکل ذاتی | **هوموپلازی** و لغزش (Stutter) |
| ⚠️ ایمنی | شروع از **DNA غیرفعال‌شده‌ی حرارتی**؛ کشت زنده = **BSL-3** |

## جدول ۹ — اسپولیگوتایپینگ
### ۹.۱. 🔎 پرایمرها و شرایط
| مورد | مقدار |
| :--- | :--- |
| **DRa** | `GGTTTTGGGTCTGACGAC` — **بیوتینیله در ۵'** |
| **DRb** | `CCGAGAGGGGACGGAAAC` |
| هدف | ناحیه‌ی **DR** (جایگاه CRISPR؛ تکرار ۳۶ bp + فاصله‌گذار) |
| تعداد فاصله‌گذار استاندارد | **۴۳** |
| هیبریداسیون | ~۶۰°C، ۱ ساعت (Reverse line blot) |
| شست‌وشو | ۲× بافر حاوی SDS در **۶۰°C**، هر بار ۱۰ دقیقه |
| آشکارسازی | **استرپتاویدین-پراکسیداز** + کمی‌لومینسانس |
| کنترل | **H37Rv** (مثبت) + **NTC** در هر ران |
| پایگاه داده | **SITVIT** (SIT و خط تکاملی) |
> ❗ محصول PCR **مخلوط قطعات** است؛ انتظار «یک باند تک» نادرست است.

### ۹.۲. تبدیل باینری به اکتال
| سه‌تایی | رقم | | سه‌تایی | رقم |
| :--- | :--- | :--- | :--- | :--- |
| ۰۰۰ | **۰** | | ۱۰۰ | **۴** |
| ۰۰۱ | **۱** | | ۱۰۱ | **۵** |
| ۰۱۰ | **۲** | | ۱۱۰ | **۶** |
| ۰۱۱ | **۳** | | ۱۱۱ | **۷** |
> **۴۲ فاصله‌گذار اول = ۱۴ رقم اکتال**؛ **فاصله‌گذار ۴۳** به‌تنهایی **رقم پانزدهم** (۰ یا ۱) ← کد **۱۵ رقمی**.

## جدول ۱۰ — تایپینگ با WGS
| رویکرد | واحد | ویژگی |
| :--- | :--- | :--- |
| **cgMLST** | آلل هزاران لوکوس **ژنوم مرکزی** | **استاندارد و قابل انتقال**؛ جانشین MLST/PFGE |
| **wgMLST** | cgMLST + لوکوس‌های جانبی | تفکیک بیشتر، استانداردسازی سخت‌تر |
| **SNP** | تفاوت‌های تک‌نوکلئوتیدی | **بالاترین تفکیک**؛ زنجیره‌ی انتقال |
> ⚠️ **آستانه‌ی SNP جهانی نیست**: به گونه، نرخ جهش، بازه‌ی زمانی، تنوع درون-میزبانی و **خط لوله** بستگی دارد ← باید **اعتبارسنجی محلی** شود.
> 📌 مراحل **تر** در فصل ۱۳؛ **تحلیل محاسباتی در این مخزن نیست**.

## جدول ۱۱ — کنترل‌ها و الزامات طراحی مطالعه
| مورد | چرا |
| :--- | :--- |
| **جدایه‌های نامرتبط** (بخش/زمان دیگر) | بدون آن‌ها «چقدر شباهت زیاد است؟» مرجع ندارد؛ کشف **کلون شایع** |
| **تکرار یک جدایه در همان ران** | سنجش **تکرارپذیری**؛ اگر یکسان نشد، ران **قابل تفسیر نیست** |
| **سویه‌ی مرجع/نشانگر** | کنترل عملکرد و **نرمال‌سازی** |
| **NTC** | کشف آلودگی (در روش‌های PCR-پایه) |
| **یکسان‌سازی غلظت DNA** | در روش‌های باندی، غلظت نابرابر خودش الگو را عوض می‌کند |
| **آستانه‌ی شباهت از پیش تعریف‌شده** | جلوگیری از **سوگیری تأییدی** |
| **داده‌ی اپیدمیولوژیک** (زمان، مکان، تماس، مقاومت) | بخشی از آزمایش است، نه ضمیمه |
| ثبت ران، Lot، پارامترها، اپراتور | قابلیت بازبینی |

## جدول ۱۲ — راهنمای انتخاب روش
| پرسش شما | روش |
| :--- | :--- |
| غربالگری سریع چند جدایه، بودجه‌ی حداقلی | **ERIC/rep-PCR** (+ تأیید بعدی) |
| طغیان بیمارستانی برای گزارش رسمی | **WGS**؛ در نبودش PFGE یا MLVA |
| مقایسه با داده‌ی جهانی، کلون شایع | **MLST** یا **cgMLST** |
| MTB — خط تکاملی | **اسپولیگوتایپینگ** |
| MTB — خوشه و انتقال | **MIRU-VNTR ۲۴** (+ اسپولیگو)؛ قطعی: **WGS** |
| زنجیره‌ی انتقال نفر-به-نفر | **WGS (SNP)** |
| «این گونه چیست؟» | ❌ ← **فصل ۱۶** |
| «این پلاسمید مقاومت منتقل می‌شود؟» | ❌ ← **فصل ۱۴** |

## جدول ۱۳ — ⚠️ ایمنی
| مورد | الزام |
| :--- | :--- |
| کار باکتریایی روتین | **BSL-2**، کابینت کلاس II |
| ⚠️ ***M. tuberculosis*** | کشت زنده **BSL-3**؛ در این فصل **فقط DNA غیرفعال‌شده**؛ غیرفعال‌سازی **اعتبارسنجی‌شده و مستند**، خروج از BSL-3 با رویه‌ی رسمی و مجوز کمیته‌ی ایمنی زیستی |
| شک به غیرفعال‌سازی ناقص | توقف کار، مهار نمونه، اطلاع به **مسئول ایمنی زیستی** |
| بلوک‌های PFGE پیش از لیز | **عفونی**؛ داخل کابینت و ظرف دربسته |
| اتیدیوم بروماید | **جهش‌زا**؛ دستکش، دفع طبق مقررات؛ رنگ ایمن‌تر ترجیح دارد |
| دستگاه CHEF | ولتاژ بالا + بافر ← **در حین ران درپوش را باز نکنید** |
| زباله و بافر | دفع طبق مقررات شیمیایی و عفونی |
> ⚠️ **دستورالعمل مؤسسه‌ی شما مقدم است.**

## جدول ۱۴ — پایگاه‌های داده و منابع استاندارد
| منبع | کاربرد |
