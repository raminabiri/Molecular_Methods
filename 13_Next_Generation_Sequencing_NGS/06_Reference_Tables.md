# ۱۳ — جداول مرجع NGS

> 🔎 = مقدار را با نسخه‌ی فعلی راهنمای رسمی Illumina تطبیق دهید.

---

## جدول ۱ — فرمول‌ها
| کمیت | فرمول |
| :--- | :--- |
| مولاریته‌ی کتابخانه | $\text{nM} = C_{(\text{ng}/\mu\text{L})}\times10^6 / (660 \times L_{\text{avg}})$ |
| پوشش | $C = N \times L / G$ |
| داده‌ی لازم برای هر نمونه | $G \times C$ |
| رقیق‌سازی Pool | $V_{\text{pool}} = C_{\text{target}} \times V_{\text{final}} / C_{\text{pool}}$ |

## جدول ۲ — Illumina DNA Prep (خلاصه)
| مرحله | حجم / شرایط |
| :--- | :--- |
| DNA ورودی | 100–500 ng در 30 µL (نرمال‌سازی ذاتی)؛ حداقل 1 ng |
| مسترمیکس تاگمنتیشن | BLT 11 µL + TB1 11 µL به ازای نمونه 🔎؛ 20 µL به هر نمونه |
| TAG | 55°C، 15 دقیقه |
| TSB | 10 µL؛ PTC: 37°C، 15 دقیقه |
| شستشو | TWB 100 µL، دو بار + یک بار نگهداری 🔎 |
| PCR | EPM 20 µL + آب 20 µL + ایندکس 10 µL |
| سیکل PCR | 5 سیکل برای 100–500 ng؛ بیشتر برای ورودی کمتر 🔎 |
| تمیز کردن | دوطرفه با SPB (85 µL رقیق، سپس 15 µL خالص روی 125 µL مایع رویی 🔎)؛ اتانول ۸۰٪ ۲ × ۲۰۰ µL |
| الوشن | RSB 32 µL ← 30 µL برداشت |
| اندازه‌ی میانگین مورد انتظار | حدود ۶۰۰ bp 🔎 |
