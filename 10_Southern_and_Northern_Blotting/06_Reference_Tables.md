# ۱۰ — جداول مرجع سادرن و نورترن

---

## جدول ۱ — مقایسه‌ی سادرن و نورترن
| ویژگی | سادرن | نورترن |
| :--- | :--- | :--- |
| هدف | DNA | RNA |
| هضم آنزیمی | ✔ | ✘ |
| ژل | آگارز ۰.۷ تا ۱٪، TAE | آگارز ۱ تا ۱.۲٪ فرمالدهید-MOPS |
| دپوریناسیون | اختیاری (> 10 kb) | ✘ |
| واسرشت | NaOH پس از ران | فرمالدهید + فرمامید + ۶۵°C پیش از ران |
| غشا | نایلون + یا نیتروسلولز | نایلون + |
| تثبیت | UV ۱۲۰ mJ/cm² یا ۸۰°C | UV |
| پروب ترجیحی | DNA (DIG) | Riboprobe (DIG) |
| $T_{hyb}$ (DIG Easy Hyb) | طبق فرمول (حدود ۳۷ تا ۴۵°C) | ۶۸°C (Riboprobe) |
| شستشوی پرسخت‌گیری | 0.5X SSC، 0.1% SDS، ۶۵°C | 0.1X SSC، 0.1% SDS، ۶۸°C |

## جدول ۴ — فرمول‌های $T_m$
| شرایط | فرمول |
| :--- | :--- |
| DNA:DNA (پروب > 50 nt) | $81.5 + 16.6\log[\text{Na}^+] + 0.41(\%GC) - 0.63(\%F) - 600/L$ |
| DIG Easy Hyb (پروب DNA) | $49.82 + 0.41(\%GC) - 600/L$؛ $T_{hyb} = T_m - 20$ تا $25$ |
| اثر عدم تطابق | حدود ۱°C کاهش به ازای هر ۱٪ |
| اثر فرمامید | حدود ۰.۶۳°C کاهش به ازای هر ۱٪ |
| پایداری نسبی | RNA:RNA > RNA:DNA > DNA:DNA |
