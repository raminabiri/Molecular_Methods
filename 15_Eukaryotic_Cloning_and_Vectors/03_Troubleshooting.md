# ۱۵ — عیب‌یابی تخصصی کشت سلول، ترانسفکشن و ویروس

---

## ۱. کشت سلول — مشکلات پایه
| مشاهده | علت ریشه‌ای | تشخیص افتراقی | اقدام |
| :--- | :--- | :--- | :--- |
| **محیط کدر و زرد در یک شب** | **آلودگی باکتریایی** | زیر میکروسکوپ: ذرات ریز **متحرک** بین سلول‌ها؛ pH افت کرده | کشت را دور بیندازید؛ ❗ درمان با آنتی‌بیوتیک توصیه نمی‌شود؛ منبع را بیابید (بن‌ماری، محیط، تکنیک) |
| **رشته‌ها یا توده‌های شناور** | **آلودگی قارچی یا مخمر** | میسلیوم یا جوانه‌زنی | دور بیندازید؛ ضدعفونی انکوباتور |
| **سلول‌ها کند رشد می‌کنند، زیستایی کم، محیط شفاف** | **مایکوپلاسما** (زیر میکروسکوپ نوری **دیده نمی‌شود**) | **آزمون اختصاصی:** PCR مایکوپلاسما یا کیت‌های مبتنی بر لوسیفراز | ❗ همه‌ی رده‌های آزمایشگاه را آزمون کنید؛ رده‌ی آلوده را دور بیندازید (یا در موارد ارزشمند، درمان اختصاصی و آزمون مجدد) |
| **سلول‌ها جدا می‌شوند** | تریپسین بیش از حد؛ آلودگی؛ pH یا اسمولاریتی؛ سلول‌های بیش‌رشد | — | زمان تریپسین؛ محیط تازه؛ پاساژ به‌موقع |
| **رشد کند با وجود شرایط درست** | پاساژ بالا؛ FBS با Lot ضعیف؛ تاریخ گذشته‌ی گلوتامین (تجزیه می‌شود) | آزمون FBS با دو Lot | ویال تازه از بانک؛ GlutaMAX |
| **تغییر مورفولوژی** | پاساژ بالا؛ **آلودگی متقاطع رده‌ها** | **تأیید هویت رده (STR profiling)** | بانک سلولی تازه؛ کار با یک رده در هر زمان در کابینت |
| **محیط صورتی تیره (قلیایی)** | $\text{CO}_2$ انکوباتور کم یا درب باز مانده | حسگر $\text{CO}_2$؛ کالیبراسیون | سرویس انکوباتور |

## ۲. ترانسفکشن با کارایی کم
### ۲.۱. ماتریس تشخیص
| آزمون | نتیجه | معنی |
| :--- | :--- | :--- |
| **کنترل GFP** | کارایی بالا (مثلاً بیش از ۵۰٪ در 293T) | سیستم کار می‌کند ← مشکل از **پلاسمید یا ژن هدف** |
| | کارایی کم | مشکل در **سلول یا معرف** |
| **زیستایی پس از Mock** | پایین | **سمیت معرف** |
| **پلاسمید روی ژل** | اسمیر یا باند خطی | کیفیت DNA |
| **تکرار با پلاسمید تجاری تازه** | بهتر | پلاسمید قبلی (اندوتوکسین، تخریب) |

### ۲.۲. علت‌ها
| علت | اقدام |
| :--- | :--- |
| **هم‌پوشانی نامناسب** (کم یا بیش از حد) | ۷۰ تا ۹۰٪؛ شمارش دقیق |
| **سلول‌های غیرفعال تقسیمی** (پاساژ بالا، محیط کهنه) | محیط تازه ۲۴ ساعت قبل؛ پاساژ پایین |
| **نسبت DNA به معرف نامناسب** | **بهینه‌سازی ماتریسی** (۳ مقدار DNA × ۳ نسبت معرف) |
| **کیفیت پلاسمید** (اندوتوکسین، نسبت‌های پایین، فرم خطی) | مینی‌پرپ **بدون اندوتوکسین**؛ ۲۶۰/۲۸۰ حدود ۱.۸؛ ابرپیچ |
| **آنتی‌بیوتیک در محیط هنگام ترانسفکشن** | محیط بدون آنتی‌بیوتیک در فاز ترانسفکشن |
| **سرم در مرحله‌ی تشکیل کمپلکس** | Opti-MEM؛ (برخی معرف‌ها سرم‌تحمل‌اند) |
| **مایکوپلاسما** | آزمون |
| **رده‌ی دشوار** (سلول اولیه، سوسپانسیون، لنفوسیت) | **نوکلئوفکشن** یا **لنتی‌ویروس** |

## ۳. سمیت
| مشاهده | علت | اقدام |
| :--- | :--- | :--- |
| مرگ وسیع ۴ تا ۲۴ ساعت پس از ترانسفکشن | **معرف زیاد**؛ PEI با نسبت بالا؛ DNA زیاد | کاهش معرف؛ **تعویض محیط ۴ تا ۶ ساعت بعد** |
| مرگ در Mock هم | معرف | نسبت کمتر؛ معرف دیگر |
| مرگ فقط با پلاسمید هدف | **پروتئین سمی** (مثلاً القای آپوپتوز) | سیستم **القایی (Tet)**؛ پروموتر ضعیف‌تر؛ زمان برداشت کوتاه‌تر |
| مرگ در انتخاب حتی با ژن مقاومت | غلظت آنتی‌بیوتیک بیش از حد؛ بیان ناکافی ژن مقاومت | منحنی کشتار؛ شروع انتخاب با غلظت کمتر و افزایش تدریجی |

## ۴. بیان پایدار و خاموشی
| مشکل | علت | اقدام |
| :--- | :--- | :--- |
| **هیچ کلنی مقاومی رشد نکرد** | کارایی ترانسفکشن صفر؛ غلظت آنتی‌بیوتیک زیاد؛ شروع انتخاب خیلی زود | کنترل GFP؛ منحنی کشتار؛ شروع ۴۸ ساعت بعد |
| **همه‌ی سلول‌ها زنده ماندند** | آنتی‌بیوتیک غیرفعال (پورومایسین به نور و دما حساس است؛ G418 در pH نامناسب) یا غلظت کم | استوک تازه، الیکوت −۲۰°C، دور از نور؛ منحنی کشتار دوباره |
| **بیان با پاساژ کم می‌شود** | **متیلاسیون پروموتر CMV**؛ از دست رفتن فشار انتخابی؛ اثر موقعیت | پروموتر **EF-1α** یا **CAG**؛ **کلون‌سازی تک‌سلولی**؛ حفظ آنتی‌بیوتیک نگهدارنده؛ بانک‌سازی زود |
| **جمعیت ناهمگن** | چندکلونی با سطوح بیان متفاوت | **کلون‌سازی تک‌سلولی** یا **FACS** برای جمعیت یکنواخت |
| **تعداد نسخه‌ی زیاد** | MOI بالا یا ترانسفکشن DNA زیاد | MOI کمتر از ۱؛ سنجش تعداد نسخه با qPCR |

## ۵. تولید لنتی‌ویروس — تیتر کم
| علت | شاهد | اقدام |
| :--- | :--- | :--- |
| **سلول 293T نامناسب** (پاساژ بالا، مایکوپلاسما، رشد ضعیف) | کارایی ترانسفکشن کنترل GFP پایین | ویال تازه؛ پاساژ پایین؛ آزمون مایکوپلاسما |
| **نسبت پلاسمیدها اشتباه** | — | نسبت توصیه‌شده‌ی همان سیستم؛ کیفیت و غلظت هر سه پلاسمید |
| **پلاسمید انتقالی بزرگ** (بیش از حدود ۸ تا ۱۰ kb کل) | — | کوچک‌کردن سازه؛ تیتر پایین‌تر را بپذیرید |
| **فیلتر نامناسب** | افت تیتر پس از فیلتر | **۰.۴۵ µm PES**، نه ۰.۲۲ و نه نیترات سلولز |
| **چرخه‌ی ذوب و انجماد** | تیتر هر بار نصف | الیکوت یک‌بارمصرف |
| **تغلیظ نامناسب** | — | سانتریفیوژ در ۴°C؛ روش ملایم |
| **تیتراسیون روی سلول نامناسب** | تیتر روی 293T بالا اما روی سلول هدف پایین | تیتر را روی **سلول هدف** بسنجید |
| **عدم استفاده از پولی‌برن** | — | ۴ تا ۸ µg/mL (⚠️ در برخی سلول‌های اولیه سمی است) |

## ۶. ترانسداکشن ناموفق در سلول هدف
| علت | اقدام |
| :--- | :--- |
| سلول هدف **مقاوم به VSV-G** (نادر) | سودوتایپ دیگر |
| MOI بسیار کم | تیتر دوباره؛ MOI بالاتر؛ اسپینوکولاسیون |
| سلول‌های تقسیم‌نشونده‌ی خاص یا در حالت استراحت | لنتی‌ویروس (نه رتروویروس گاما)؛ زمان تماس بیشتر |
| محیط حاوی مهارکننده (سرم بالا، هپارین) | محیط کم‌سرم در فاز ترانسداکشن |
| ❗ **بیان ژن هدف سمی** | سیستم القایی |

## ۷. ایمنی — خطاهای رایج و پرخطر (سطح سرپرست)
| خطا | خطر | اقدام اصلاحی سازمانی |
| :--- | :--- | :--- |
| استفاده از **سوزن یا تیغ** در کار ویروسی | **مواجهه‌ی تزریقی** | ممنوعیت مطلق اجسام تیز؛ استفاده از پیپت پلاستیکی |
| سانتریفیوژ ویروس **بدون سطل دربسته** | آئروسل | سطل‌های Aerosol-tight؛ باز کردن در کابینت |
| آسپیراتور خلأ متصل به سینک بدون تله | انتقال آئروسل به سیستم | تله با سفیدکننده + فیلتر HEPA روی خط خلأ |
| دور ریختن محیط ویروسی در سینک | انتشار | سفیدکننده ۱۰٪، ۳۰ دقیقه، سپس طبق مقررات |
| انکوباتور مشترک بدون برچسب | مواجهه‌ی ناخواسته‌ی همکاران | برچسب خطر زیستی و ثبت زمان‌بندی |
| آموزش ندیده بودن کاربر | — | آموزش مستند و تأیید صلاحیت پیش از کار |
