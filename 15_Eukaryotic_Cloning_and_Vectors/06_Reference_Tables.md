# ۱۵ — جداول مرجع: کشت سلول، ترانسفکشن و وکتورهای ویروسی

> ⚠️ عددهای نشان‌دار با **🔎** را پیش از استفاده با **دفترچه‌ی همان محصول/Lot** و **دستورالعمل مؤسسه** تأیید کنید. برای وکتورهای ویروسی، **دستور کمیته‌ی ایمنی زیستی مؤسسه بر هر عدد این جدول‌ها مقدم است**.

## جدول ۱ — فرمول‌ها
| کمیت | فرمول |
| :--- | :--- |

| زیستایی (%) | $\dfrac{\text{زنده}}{\text{زنده} + \text{آبی}} \times 100$ |
| حجم لازم از سوسپانسیون | $V = \dfrac{N_{\text{لازم}}}{\text{غلظت سوسپانسیون}}$ |

| **مجوز** | تأیید کتبی **کمیته‌ی ایمنی زیستی مؤسسه** برای همان سازه و رده؛ ارزیابی مخاطره‌ی مکتوب (❗ ژن‌های انکوژن/سمی سطح خطر را بالا می‌برند) |

| **اجسام تیز** | **مطلقاً ممنوع** — سوزن، سرنگ، تیغ، شیشه‌ی شکستنی |
| **سانتریفیوژ** | فقط با **سطل دربسته**؛ باز کردن سطل **داخل** کابینت |
| **محافظت فردی** | روپوش بسته، **دو جفت دستکش**، محافظ چشم |
| **ضدعفونی** | هیپوکلریت **تازه** طبق دستور مؤسسه؛ تمام زباله‌ی عفونی اتوکلاو |
