جدول ساختار داده‌ها در اکسل (فرض کنید داده‌ها از سطر ۲ شروع می‌شوند):

* **ستون A:** Sample_ID
* **ستون B:** Group
* **ستون C:** $C_t$ Target
* **ستون D:** $C_t$ Ref1
* **ستون E:** $C_t$ Ref2

| ستون | عنوان | فرمول اکسل (در سطر ۲) |
| :--- | :--- | :--- |
| **F** | Ref_GeoMean | `=EXP(AVERAGE(LN(D2), LN(E2)))` |
| **G** | Delta_Ct | `=C2 - F2` |
| **H** | Control_Avg_Delta_Ct | `=$J$2` *(ارجاع به سلول میانگین کنترل)* |
| **I** | Delta_Delta_Ct | `=G2 - H2` |
| **J** | Fold_Change | `=2^(-I2)` |

*فرمول سلول J2 (میانگین $\Delta C_t$ گروه کنترل):*
`=AVERAGEIF(B2:B10, "Control", G2:G10)`

<details>
<summary><b>فصل ۶: کدنویسی کامل و یکپارچه در R (از صفر تا صد)</b></summary>

این خط لوله شامل وارد کردن داده‌ها، محاسبات $2^{-\Delta \Delta C_t}$، تست‌های آماری و رسم نمودار استاندارد مقاله است:

```R
# ---------------------------------------------------------
# ۱. نصب و فراخوانی پکیج‌های لازم
# ---------------------------------------------------------
if (!requireNamespace("BiocManager", quietly = TRUE))
    install.packages("BiocManager")

packages <- c("tidyverse", "ggpubr", "rstatix", "readxl")
new_packages <- packages[!(packages %in% installed.packages()[,"Package"])]
if(length(new_packages)) install.packages(new_packages)

library(tidyverse)
library(ggpubr)
library(rstatix)

# ---------------------------------------------------------
# ۲. ساخت و بارگذاری داده‌های آزمایشی
# ---------------------------------------------------------
set.seed(123)
qpcr_data <- data.frame(
  Sample_ID = rep(paste0("S", 1:12), each = 3),
  Group = rep(c("Control", "Treated_A", "Treated_B"), each = 12),
  Target_Gene = c(rnorm(12, 25.0, 0.2), rnorm(12, 21.5, 0.3), rnorm(12, 26.8, 0.25)),
  Ref_GAPDH   = rnorm(36, 18.0, 0.15),
  Ref_ACTB    = rnorm(36, 19.2, 0.18)
)

# ---------------------------------------------------------
# ۳. پردازش و محاسبات 2^-ddCt
# ---------------------------------------------------------
# الف) میانگین تکرارها و میانگین هندسی مرجع
processed_data <- qpcr_data %>%
  group_by(Sample_ID, Group) %>%
  summarise(
    Mean_Target = mean(Target_Gene, na.rm = TRUE),
    Mean_GAPDH  = mean(Ref_GAPDH, na.rm = TRUE),
    Mean_ACTB   = mean(Ref_ACTB, na.rm = TRUE),
    .groups = "drop"
  ) %>%
  mutate(
    Ref_GeoMean = sqrt(Mean_GAPDH * Mean_ACTB),
    Delta_Ct    = Mean_Target - Ref_GeoMean
  )

# ب) محاسبه میانگین Delta Ct گروه کنترل
control_mean_dct <- processed_data %>%
  filter(Group == "Control") %>%
  summarise(m = mean(Delta_Ct)) %>%
  pull(m)

# ج) محاسبه Delta Delta Ct و Fold Change
final_results <- processed_data %>%
  mutate(
    Delta_Delta_Ct = Delta_Ct - control_mean_dct,
    Fold_Change    = 2^(-Delta_Delta_Ct)
  )

# ---------------------------------------------------------
# ۴. تحلیل‌های آماری (روی Delta Ct)
# ---------------------------------------------------------
# آنالیز واریانس ANOVA
anova_test_res <- final_results %>%
  anova_test(Delta_Ct ~ Group)

# تست تعقیبی Tukey
stat_pvals <- final_results %>%
  tukey_hsd(Delta_Ct ~ Group) %>%
  add_significance() %>%
  add_xy_position(x = "Group")

# ---------------------------------------------------------
# ۵. رسم نمودار انتشار به همراه Error Bar و p-value
# ---------------------------------------------------------
summary_plot <- final_results %>%
  group_by(Group) %>%
  summarise(
    Mean_FC = mean(Fold_Change),
    SEM_FC  = sd(Fold_Change) / sqrt(n()),
    .groups = "drop"
  )

plot_output <- ggplot(summary_plot, aes(x = Group, y = Mean_FC, fill = Group)) +
  geom_bar(stat = "identity", width = 0.6, color = "black", alpha = 0.8) +
  geom_errorbar(aes(ymin = Mean_FC - SEM_FC, ymax = Mean_FC + SEM_FC), width = 0.2) +
  geom_jitter(data = final_results, aes(x = Group, y = Fold_Change), width = 0.1, size = 2) +
  geom_hline(yintercept = 1, linetype = "dashed", color = "red") +
  scale_fill_brewer(palette = "Set1") +
  theme_pubr() +
  labs(
    title = "Relative Gene Expression Analysis",
    y = "Fold Change (2^-ΔΔCt)",
    x = "Experimental Groups"
  ) +
  stat_pvalue_manual(stat_pvals, label = "p.adj.signif", y.position = c(4.0, 3.5, 2.5))

# نمایش نمودار
print(plot_output)



انحراف معیار تکرارها (SD of Replicates):مقدار SD مربوط به $C_t$ تکرارهای فنی یک نمونه نباید از ۰.۲۸ (حداکثر ۰.۵) بیشتر باشد.بررسی NTC (No Template Control):عدم مشاهده هیچ سیگنالی در چاهک کنترل بدون الگو؛ وجود $C_t < 35$ نشان‌دهنده آلودگی است.داده‌های ورودی به تست آماری:الزامی: آزمون‌های آماری (t-test و ANOVA) باید روی مقادیر $\Delta C_t$ انجام شوند (زیرا داده‌های $\Delta C_t$ توزیع خطی و نرمال دارند، اما مقادیر Fold Change نمایی هستند).
